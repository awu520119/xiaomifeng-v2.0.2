# 业务流程图 - NFC 卡平台 MVP

```text
                        ┌──────────┐
                        │   开始   │
                        └────┬─────┘
                             ▼
          ┌────────────────────────────────┐
          │ S1 每张卡生成唯一领取链接并线下写入 │
          └────────────────┬───────────────┘
                           ▼
          ┌────────────────────────────────┐
          │ S2 碰卡打开链接，登录并确认领取 │
          └────────────────┬───────────────┘
                           ▼
                 ◇ D1 领取码有效且未使用? ◇
                    ├─ 否 → 提示链接无效或已领取 → 结束1
                    └─ 是
                       ▼
      ┌─────────────────────────────────────────┐
      │ S3 卡绑定用户、发放1次权益并计入激活卡数 │
      └──────────────────┬──────────────────────┘
                         ▼
          ┌────────────────────────────────┐
          │ S4 碰现场贴片召唤（通用链接，不读卡）│
          └────────────────┬───────────────┘
                           ▼
              ◇ D2 绑定用户有可用卡权益? ◇
                    ├─ 否 → 提示无可用权益 → 结束2
                    └─ 是
                       ▼
      ┌──────────────────────────────────────┐
      │ S5 选定卡，核销权益、建单并记账       │
      └──────────────────┬───────────────────┘
                         ▼
          ┌────────────────────────────────┐
          │ S6 复用现有拍摄与上传           │
          └────────────────┬───────────────┘
                           ▼
                    ◇ D3 拍摄完成? ◇
                    ├─ 否 → S7 沿用失败/超时/取消流程 ─┐
                    └─ 是 → S8 交付成片，转藏品卡（默认1年） ─┤
                                                       ▼
                                          ┌────────────────────┐
                                          │ S9 更新逐卡业务记录 │
                                          └──────────┬─────────┘
                                                     ▼
                              ┌────────────────────────────────┐
                              │ 结束3：后台逐卡查询、按激活数对账 │
                              └────────────────────────────────┘
```
