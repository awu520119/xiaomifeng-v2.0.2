# 下单使用与订单关联 PRD

> 版本 v3.2 · 2026-10-21 · 本地 Mock 原型

用户用价格券支付正数金额订单，或用账户体验权益创建无需支付的体验订单，并能够核对履约与退款返券结果。

## 选择与下单

1. **选择**：演示手机号、主题/套餐及优惠选项；价格券默认推荐可用券中优惠最高的一张，允许不使用，禁用项显示不适用、门槛、有效期、占用或零元应付原因。
2. **价格券**：每单一张，优惠后应付为 0 时不可用；创建订单锁券，支付成功记录用券并进入待使用服务；取消或模拟超时关闭释放。
3. **体验权益**：仅提供有效且有次数、适用商品的权益；下单预占一次并进入「待使用」，不拉起支付，完成服务后计实际体验。

## 订单与退款

1. **详情**：订单、商品、关联券码、应付、状态、退款金额及返券结果；支持模拟支付、关闭、完成服务和符合条件的退款。
2. **全额退款**：未使用服务时返还仍有效且未作废的原价格券，保留原券码与历史。过期不返还；返还后可重新下单使用。
3. **不退权益**：部分退款、已履约订单不返券、不退权益；部分退款按实付 50% 演示，未履约服务仍可继续履约。
4. **防重复**：同一待支付券不能用于第二单，已关闭/已退款订单不能重复处理；发生退款后记录保留结果，避免重复退款或返券。
5. **边界**：零实付体验订单无金额退款入口；取消、售后及有效期共用口径引用《优惠券体系PRD.md》。以上均为本地 Mock 演示，不发起真实支付退款。
