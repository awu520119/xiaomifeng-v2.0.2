## 导航与配置

1. **导航**：一级「营销管理」，二级「优惠券管理」「发放记录」「活动发券」，无三级导航。
2. **创建类型**：价格券保留满减、折扣，体验券保留主题/套餐搜索多选。去掉可兑换次数配置、每人限领、内部备注；使用说明改为必填「使用规则」。新体验券为单次，既有券次数不重置。
3. **列表与操作**：优惠券列表保留券名称、券类型、适用范围、有效期、状态、发放概况；具体操作和抽屉见《优惠券列表PRD.md》。
4. **编辑**：发生用户绑定或作废后，规则、期限和额度只读；名称、使用规则可修改。停用阻止继续发放/领取，已绑定券沿原规则使用；未过期且有剩余额度可恢复启用。

## 发放、券池与领取

1. **唯一券码**：每张实际券有唯一券码。体验券按总量自动备码，不提供手动生成入口；分配及领取使用同一原券码，重复打开不换码。价格券实际发放或领取时创建。
2. **总量**：自动备码不计发放，用户绑定后计入已发放与已领取；未领取券作废占用额度，作废不返额度。所有方式共用总量，不再按用户设置限领数量。
3. **定向发放**：批量手机号逐条发券，同一号码出现多次即发多张；手机号格式或整批额度校验失败时整批不发。成功产生批次，保留每一张的记录。
4. **公开领取**：价格券固定复用通用二维码及链接，仅下载和复制；沿用券状态、总量、有效期，不另设入口总量或限领配置。
5. **单码领取**：体验券通过单券二维码、链接或券码绑定手机号，同码已绑定用户重复打开显示原结果，其他用户不可占用；领取券后可由活动发券将体验权益发到账户。
6. **追踪**：券码详情精简为状态、接收用户、领取时间、有效期及二维码/链接，不展示权益到账时间、体验次数或订单。实际绑定后的券统一进入发放记录，覆盖三种方式。

## 活动发券与体验权益

1. **发放流程**：活动发券选择指定体验券码与手机号，将权益直接发至账户；关联订单选填，记录券码、发放用户、订单、操作人及时间，见《活动发券PRD.md》。
2. **防重复与账户**：已绑定券只可发给原用户；同码权益仅可到账一次，未生效、过期、作废或已到账不能再次发放。未绑定券还须检查券未停用。
3. **期限**：体验权益沿用原券生效与截止时间，过期不能新建订单或确认履约。
4. **体验使用**：权益到账后用户选择适用商品体验，下单预占权益并产生无需支付订单，完成服务后记录实际体验。新体验券单次，历史多次权益按既有余额使用。

## 价格券下单与售后

1. **可用条件**：满足范围、门槛、有效期且无待支付订单占用；价格券每单一张，默认推荐最优惠可用券，可手动改选。优惠后应付为 0 时本单不可用，并展示原因。
2. **占用与使用**：创建待支付订单锁券，支付成功记录使用并进入「待使用」服务状态；取消或超时关闭释放锁定。支付失败不会写使用记录，未关闭前保持占用。
3. **全额退款返券**：未使用服务的订单全额退款时，返还仍在有效期内且未作废的原价格券；保留原券码及历史使用记录，历史标记返还。过期原券不返还。
4. **不退权益**：部分退款不返券、不退权益；已履约订单即使全额退款也不返券、不退权益。原型以实付 50% 演示部分退款；部分退款后的未履约服务仍可完成。
5. **体验订单边界**：零实付体验订单无金额退款入口；本期返券规则适用于价格券，不新增体验权益自动退还规则。

## 记录与演示边界

1. **统一记录**：发放记录展示已绑定用户的券，按手机号、日期、状态筛选，包含券名称、券类型、状态、领取用户、关联订单号、发放方式、有效期和作废操作，见《发放记录PRD.md》。
2. **使用与退款**：订单保留使用、退款及返券结果，价格券历史不因返还而删除。体验权益到账不等同完成服务，使用历史按实际履约记录保留。
3. **本地演示**：使用本地 Mock 和浏览器存储，不连接真实用户、支付、退款、履约服务；优惠成本与分成不在本期范围。
