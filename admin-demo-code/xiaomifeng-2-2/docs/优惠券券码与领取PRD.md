## 券码行内管理

1. **入口**：点击优惠券列表每行的「券码」后，在原行下方展开券码清单；券码不另设页面或抽屉。
2. **生成**：选择券与数量，数量为1至10000并受剩余总量限制；每张生成一个唯一券号，默认未领取，按原券保存商品、优惠规则及固定时间快照。
3. **下载**：生成时下载CSV，包含唯一券号、名称、优惠内容、生效日期和失效日期。生成一张就占一个名额，后续兑换只绑定原券，不重复占用。
4. **操作**：券号可复制；未领取且未过期、未作废的券可查看和下载兑换二维码。三类券均可手动核销和作废，使用规则统一见《优惠券发放明细PRD.md》。
5. **二维码文件**：下载为PNG，保留白色边距以便扫描；码内指向本地原型兑换页并预填唯一券号。

## 券码兑换页

1. **进入**：可扫描单张券的兑换二维码，或打开二维码中的链接；输入手机号模拟登录。
2. **展示**：匹配到券后展示名称、优惠内容、体验商品及固定生效、失效日期；未知码不执行兑换。
3. **校验**：同一码只可绑定一名用户；已领取、已作废、已过期或已核销码不能再次兑换；校验同一手机号对该券的累计限领数。
4. **未生效**：可以提前兑换获得券，但核销仍须等到生效时间；不会提前或延长有效区间。
5. **结果**：显示领取用户、唯一券号、状态及两项固定日期，可返回后台定位到同一张券。兑换不等于使用，不扣体验次数。

## 指定手机号扫码领取

1. **配置入口**：优惠券列表「领取二维码」，默认限定指定手机号；可切换所有登录用户。指定名单按11位格式校验并去重，错误时不生成入口。
2. **生成**：每次生成独立入口，保留当次允许名单；提供PNG下载和链接复制，入口本身不占券名额。
3. **领取**：用户手机号必须在名单内；所有用户模式不限名单，但仍受总量、每人限领、停用和失效校验。领取成功时创建一个新的唯一券号并占一个名额。
4. **固定日期**：领取后沿用原券生效和失效日期，不再按领取日重算；未来生效券可领不可核销。
5. **反馈与追溯**：名单外、重复超限、名额耗尽等均明确提示，不新增记录；成功展示券号及权益，并可在后台发放记录找到对应券。

## 演示范围

1. **数据**：同一浏览器来源内本地保存和同步，后台刷新后仍可查看已生成和已领取数据；没有接入真实登录、手机号验证码、后端、跨设备同步、订单或支付系统。
2. **身份**：领取页明确说明输入手机号为本地模拟登录，不将此校验宣称为真实用户身份认证。
3. **边界**：券码兑换仅绑定既有券，通用领取二维码成功才生成新券，两种二维码不混为同一动作；后台通过同一唯一券号继续核销和作废。
