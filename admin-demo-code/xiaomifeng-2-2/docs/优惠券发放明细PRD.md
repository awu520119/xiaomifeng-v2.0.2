## 页面目标

让运营和客服能够跨优惠券查询用户持券、第三方兑换码及核销状态；也支持从某张优惠券详情带条件进入此页。持券和未兑换码分属两个页签，不混计数量。

## 查询与展示

- **持券记录**：按优惠券名称/券码、持券用户手机号和状态筛选；展示权益、状态、用户、来源、已用/总次数、券码、最近核销订单、发放时间和有效期截止，可查看逐次核销记录。
- **第三方兑换码**：按优惠券名称/兑换码/批次号、渠道和状态筛选；展示渠道、批次、状态、生成及售出时间、兑换用户、兑换时间和权益截止时间。
- 从优惠券详情跳转时，自动按当前优惠券和对应页签筛选；可清除券筛选查看全部记录。

## 状态与操作

- 第三方兑换码生成后为「未售出」；模拟渠道售出后为「待兑换」，再模拟用户兑换后为「已兑换」。兑换时记录用户和时间，生成关联持券记录，并按兑换时间加券规则 N 天计算权益截止时间。
- 「未售出」「待兑换」兑换码和「待使用」持券记录可作废；待兑换码作废前提示先确认渠道退款。作废不返还发放额度。
- 体验权益券的「待使用」或「部分使用」记录可模拟核销一次；校验适用拍摄点、主题、有效期、剩余次数和订单号不重复。剩余次数大于零时为「部分使用」，用完后为「已核销」。
- 已过期、已作废和已核销的持券记录不能再次核销；价格券仅展示已有核销结果。
- 停用优惠券不影响已发出的券和已导出的兑换码在有效期内继续使用。

## 本期边界

使用本地 Mock 演示查询、筛选、批次追踪、作废、售出、兑换和体验核销；不连接真实美团/抖音接口或服务订单。模拟售出不代表已取得渠道销售凭据，价格券的真实订单用券不在本期原型中。
