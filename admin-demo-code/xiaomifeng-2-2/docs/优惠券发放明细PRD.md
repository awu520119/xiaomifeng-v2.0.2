## 发放记录

1. **发放记录**：仅展示已经绑定用户的券，包含定向下发、券码兑换和扫码领取；每行一张有唯一券号的券。
2. **券码**：优惠券管理列表中按行展开查看未领取和已领取的券号；与发放记录使用同一数据，兑换后同一券号仍可追溯。
3. **字段**：唯一券号/券码、优惠券名称、类型、优惠内容、状态、使用情况、领取用户、生效日期、失效日期、操作。券号支持复制，不把身份信息藏在深层详情。
4. **查询**：一个搜索框查询券号、手机号或券名，可组合状态筛选；重置保留从某种券带入的范围，查看全部记录退出范围。均沿用白卡表格和分页样式，不使用三个并列 Tab。
5. **日期**：显示实际规则快照的固定起止时间，定向发放、兑换和扫码不会改变这两项日期。

## 状态与体验次数

1. **状态**：

    | 状态 | 含义 |
    | --- | --- |
    | 未领取 | 已生成券码，尚未绑定用户，且当前在有效区间 |
    | 未生效 | 还没有到生效时间，可提前领取，不可核销 |
    | 待使用 | 已领取、有剩余权益且处于有效期 |
    | 已核销 | 折扣/满减券已使用一次，或体验次数全部用完 |
    | 已过期 | 已超过失效时间且未全部用完 |
    | 已作废 | 人工取消剩余权益，不能继续领取或核销 |

2. **使用进度**：体验券显示「已使用X/N次」「剩余Y次」，不单列「部分使用」状态；尚有次数的有效用户券继续为待使用。部分已用后作废会标出未用次数已作废，保留历史使用。
3. **状态优先级**：人工已作废和全部已核销优先保留；未用完的券按当前时间计算过期或未生效，随后按是否绑定用户区分未领取和待使用。

## 手动核销

1. **入口**：三类券均提供「核销」，待使用或有效期内未领取的券可以操作；未领取券须同时绑定核销用户手机号，校验每人限领，不另建券号。
2. **共同校验**：未生效、已过期、已作废或已用完时禁止核销；订单号须非空且不能与任何既有核销订单重复；商品必须在券的适用范围。
3. **体验券**：选择本次兑换的主题体验商品，每成功核销一次扣减一次，记录对应商品、拍摄点、主题、订单和时间；用完前可以继续核销，最后一次后转为已核销。
4. **折扣券**：填写订单原价与订单商品，达到门槛才可用；本单优惠为原价乘以「1－折扣/10」，按分四舍五入，最多优惠到0元，一次用完。
5. **满减券**：填写订单原价与商品，达到门槛才减指定金额，一次用完。满减金额创建时必须小于门槛，不能产生负数实付。
6. **反馈**：不满足条件时给出明确原因，不写入记录、不扣次数；成功后更新状态、次数及核销记录，券号保持不变。核销界面展示本单优惠及优惠后应付，仅为本地规则演示，不发起支付。

## 作废与核销记录

1. **作废**：有未用完权益且未作废的券可人工作废，包括未领取券和已用过一次但仍有剩余的体验券；二次确认说明已核销记录保留、未用权益不可再用及名额不返还。
2. **不可逆**：全部核销后的券不再作废；作废后不可领取、兑换或继续核销，不恢复发放名额，不删除历史核销。
3. **详情**：按唯一券号查看领取用户、发券方式、优惠规则、可兑换/适用商品、生效失效日期和按次核销记录；价格券记录包含订单原价和本单优惠，体验券记录明确兑换了哪个商品。
4. **本地保存**：演示数据保存在当前浏览器，领取页与后台在同一来源下同步；正式并发、身份校验、订单履约和财务结算仍需真实服务承接。
