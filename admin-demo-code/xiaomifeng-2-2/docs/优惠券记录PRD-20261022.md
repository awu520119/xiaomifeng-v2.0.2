# 优惠券记录 PRD

> 版本 v1.0　·　日期 2026-10-27

*需求场景：运营人员查询每张已领取用户券的持有人、获取方式和当前使用状态，并执行允许的作废操作。*

## 一、优惠券记录—权限说明

1. **权限控制**：
    - 须具有「优惠券记录」-「查询」功能权限。
    - 须具有该券的发券权限。
    - **作废**：须具有「优惠券管理」-「编辑」权限。

## 二、优惠券记录—筛选项说明

1. **券名称、券码、手机号关键词搜索**：关键词输入。按任一对应字段包含关键词匹配。

2. **日期筛选**：日期范围。以用户券实际绑定时间查询，包含所选开始日和结束日全天。
    - 支持清空。

3. **获取方式筛选**：单选。「定向发放」「公开领取」「券码领取」，支持清空。

4. **使用状态筛选**：单选。包括待使用、使用中、已使用、已过期、已作废，支持清空。

## 三、优惠券记录—列表说明

1. **发放人**：主要展示发放账号 ID，账号名称在下方辅助展示。
    - 仅定向发放展示发放账号 ID 和名称；公开发放及券码领取无法追踪发放人，展示「-」。

2. **使用状态**：

| 状态 | 业务含义与触发条件 |
| --- | --- |
| 「待使用」 | 已领取，仍有效，未被订单占用且尚未完成该券对应使用；体验权益到账本身不表示已完成服务 |
| 「使用中」 | 价格券被待支付订单占用；或体验券已创建体验订单但尚未完成服务 |
| 「已使用」 | 价格券已经用于成功支付；或体验券已完成对应体验服务 |
| 「已过期」 | 未作废、未完成使用且未被订单占用，并已超过单券截止时间，不可继续使用 |
| 「已作废」 | 人工执行作废成功，不可继续使用 |

3. **获取方式和获取时间**：
    - 获取方式展示「定向发放」「公开领取」「券码领取」。
    - 获取时间为用户券实际绑定当前用户的时间。

4. **关联订单号**：展示当前占用订单或已关联订单。
    - 有订单时支持复制及查看完整号码，无订单展示「—」。

5. **体验券编号**：仅体验券展示对应的独立编号。
    - 体验券展示独立「TY-」连续编号。
    - 满减、折扣和特价券展示「—」。

6. **有效期**：第一行展示领取后有效天数，第二行展示已固化的具体截止时间。

7. **作废**：仅使用状态为「待使用」且未被订单占用时允许操作。
    - 点击后确认「确认作废该优惠券？」并提示「作废后用户不可继续使用，且不可恢复。」
    - 确认成功后状态更新为「已作废」，不可继续使用或再次作废，并保留原发放及领取记录。
    - 「使用中」「已使用」「已过期」「已作废」状态不提供作废操作。

8. **排序**：按获取时间倒序。

9. **退款与状态**：
    - 体验券全额退款后返还原用户，仍有效时恢复「待使用」；
    - 价格券（满减、折扣、特价）退款未返券时保持「已使用」。
