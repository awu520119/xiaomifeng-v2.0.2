## 领取流程

1. **公开领取**：进入固定链接或二维码，核对券内容、范围、有效期并确认手机号；总量及启停规则引用《优惠券体系PRD.md》。
2. **体验券领取**：链接带入券码，无须重复输入；无链接时可粘贴券码或单券领取链接。成功后绑定同一券码，发放方式为「券码领取」。
3. **重复领取**：同一手机号已领取该券码时直接展示原领取结果，其他用户不能再次领取。
4. **成功反馈**：展示券、状态、期限和「查看我的优惠券」；体验券提示出示券码，由工作人员在活动发券中确认后将权益发到账户。领取不自动发放体验权益。
5. **异常反馈**：入口错误、已停用、过期、作废、无额度分别提示原因，不新增券或到账记录。
