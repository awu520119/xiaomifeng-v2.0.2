# 值班排班日历 PRD

> 版本 v1.0　·　日期 2026-11-03

*需求场景：管理员查看每日值班覆盖情况，按日期安排多个班次，并查看、调整或删除对应排班。*

## 值班日历

1. **入口与范围**：进入「值班排班」后展示当前月份的周一至周日日历；本期新建排班负责范围为「全部拍摄点」。
2. **日期切换**：支持上一月、下一月及「今天」。切换月份时，选中目标月份的同一日；若目标月份不存在该日，则选中月末。「今天」返回当前日期及所在月份。
3. **日期状态**：区分今天、选中日期及非本月日期。点击非本月日期时，切换到该日期所在月份。
4. **未安排日期**：展示「未安排」和「安排值班」入口，点击日期格打开该日新增排班，日期自动带入并锁定。
5. **已安排日期**：按班次开始时间从早到晚展示人员姓名、班次名称和值班时间；跨天结束展示「次日」。最多展示两条，超过两条展示「另有 {数量} 条」，数量为当天总记录数减二。点击日期格查看当日全部排班。
6. **同日多班次**：同一天允许安排多条排班，每条记录选择一名在岗人员及一个班次。按当前原型口径，全部拍摄点范围内同一时段仅允许一条排班；不重叠的班次可以安排不同人员或同一人员。
    - 时间以排班日期及开始、结束时间共同确定；结束时间早于开始时间时，结束日期为次日。
    - 开始时间等于另一条排班结束时间不算重叠；跨日期排班同样参与重叠校验。
7. **管理入口**：提供「运维人员」「班次设置」「批量排班」。人员及班次保存后，新建排班使用最新可选配置。

## 排班详情

1. **展示内容**：弹窗顶部显示完整日期及星期；按开始时间展示当天全部排班卡片，每条展示责任人、飞书账号、班次、值班时间及负责范围。
2. **账号区分**：责任人姓名取该排班保留的姓名；飞书账号取当前运维人员的有效绑定信息，按「{飞书账号}（{姓名}）」展示。未绑定或人员已移除时显示「—」。
3. **历史信息**：已保存排班保留当时的姓名、班次名称、起止时间及范围。历史「全局」展示为「全部拍摄点」；历史分拍摄点记录保留原范围，不因查看或修改责任人自动扩大范围。
4. **人员异常**：若责任人已从运维人员中移除，则展示「人员已移除」状态及重新选择人员的提示；若当前人员未绑定飞书，则展示「飞书未绑定」。两种状态不得混淆。
5. **多条记录**：各卡片独立显示操作。正文超出弹窗可见高度时内部滚动，各操作仅作用于对应记录。
6. **继续安排**：未处于调整状态时提供「添加排班」，打开当前日期的单日新增；保存后回到该日详情。取消新增时，若当天仍有排班，则返回详情。

## 原位调整排班

1. **进入调整**：点击某条记录的「调整排班」后，在当前详情中编辑该条；若当日有多条，暂时仅展示当前编辑记录，并说明保存或取消后恢复当天全部排班。
2. **回显与可修改字段**：日期保持不变；责任人和班次回显原值，可选择新的在岗人员和当前班次；负责范围只读。
3. **原班次保留**：原班次已删除或时间已修改时，仍展示该排班保存的班次及时间。保留原班次选项时沿用原起止时间；选择其他班次时使用所选班次当前时间。
4. **原人员已移除**：保留原姓名并明显提示「原值班人员已移除」，责任人需重新选择在岗人员后才能保存。
5. **保存校验**：无修改时「保存调整」不可用。保存前校验人员在岗、班次有效及与其他排班的时间重叠；当前记录自身不参与冲突判断。错误显示在当前编辑区域，保留输入并说明冲突日期、人员、班次和时间。
6. **保存成功**：仅更新当前记录，详情原位展示结果并恢复当日全部卡片；月历同步更新，提示「排班已调整」。
7. **取消与关闭**：点击「取消」丢弃本次输入并恢复原详情；若有未保存修改且点击弹窗关闭，则展示「放弃本次调整？」及「放弃修改」「继续编辑」。详情不通过点击遮罩关闭。

## 删除排班

1. **二次确认**：点击单条「删除排班」，确认中展示该条日期、人员、班次及时间，并提供「删除」「取消」。
2. **删除结果**：确认后仅移除该条记录并提示「排班已删除」；取消不改变记录。若还有其他记录，详情继续展示剩余记录；若最后一条被删除，则关闭详情，月历该日期显示「未安排」。
3. **通知**：排班新增、调整和删除不发送飞书通知。

## 待确认事项

1. **重叠班次的人员容量**：当前原型限制任意排班时间重叠；是否未来允许不同人员在重叠时段共同值班，需业务确认。
2. **历史排班修改权限**：当前原型未限制过去日期的新增、调整或删除；正式规则是否限制已结束排班及允许操作的角色，待确认。
3. **人员历史账号**：人员移除后原排班仍保留姓名，但当前原型未保留完整账号快照；历史系统账号、飞书账号是否需按当时信息保留，待确认。
