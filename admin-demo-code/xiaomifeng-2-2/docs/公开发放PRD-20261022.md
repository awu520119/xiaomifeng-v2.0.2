# 公开发放 PRD

> 版本 v1.0　·　日期 2026-10-27

*需求场景：获授权的运营人员可公开发放通用领取二维码和链接，供用户自主领取优惠券。*

## 变更记录

| 版本 | 日期 | 变更内容 | 提出人 |
| --- | --- | --- | --- |
| v1.0 | 2026-10-27 | 初版 | 用户 |

## 一、公开发放—权限说明

1. **权限控制**：
    - 须具有「优惠券列表」-「发放」功能权限。
    - 须具有该券的发券权限。

## 二、二维码和链接说吗

1. **券名称和类型**：只读展示所选优惠券的名称和类型。

2. **二维码和领取链接**：同一券重复打开时复用现有入口。

3. **下载和复制**：支持下载二维码或复制领取链接，供线上分享或线下展示。

## 三、用户领取

1. **领取校验**：
    - 价格券（满减、折扣、特价）：校验每位用户累计限领一张；定向发放与公开领取合并计算。
    - 校验不通过时提示原因。
