> 版本 v1.0　·　日期 2026-10-22

*需求场景：获授权的运营人员取得价格券的通用领取二维码和链接，供用户自主领取优惠券。*

## 一、公开领取—权限说明

1. **后台入口**：后台优惠券列表的满减券或折扣券「发放」中选择「公开发放」，打开标题为「公开领取」的弹窗。后台体验券列表仍通过逐张券码提供领取凭证。
    - 发券中心的三类券公开领取见[《发券 PRD》](发券PRD-20261022.md)。

2. **权限与额度**：操作权限引用[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「权限说明」。
    - 领取受该券模板状态和共用总量限制，不在本页另外配置数量、限领或有效期。

## 二、公开领取—详情字段说明

1. **优惠券**：自动带出所选券名称。

2. **券类型**：自动带出满减券或折扣券标签。

3. **公开领取二维码**：对应该券的通用领取入口。
    - 同一券重复打开时复用现有通用入口。

4. **领取链接**：与二维码指向同一领取入口，只读展示。

## 三、公开领取—领取与操作说明

1. **下载二维码**：下载当前入口二维码，供线上分享或线下展示。
    - 下载行为不创建用户券，不占领取额度。

2. **复制领取链接**：复制当前只读链接，复制行为不改变券状态或领取量。

3. **领取结果**：用户通过入口成功领取后，为该次领取分配独立用户券码、绑定接收手机号并计算截止时间，新增券使用记录。
    - 失败时不新增用户券或扣减额度。

4. **入口控制**：本页不提供单独停用入口。
    - 优惠券整体暂停或额度用尽后，按券模板状态限制新领取，已领取券保留原信息。
