# 公开领取 PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：获授权的运营人员取得价格券的通用领取二维码和链接，供用户自主领取优惠券。*

## 变更记录

| --- | --- | --- | --- |
| v1.0 | 2026-10-22 | 初版；补齐领取身份、提交校验与重复领取口径 | 用户 |

## 一、公开领取—权限说明

1. **权限控制**：
    - 须具有「营销管理」下「优惠券管理」的「发放」功能权限。
    - 须有该券的「发券权限」。

## 二、公开领取—详情字段说明

1. **优惠券**：自动带出所选券名称。

2. **券类型**：自动带出满减券或折扣券标签。

3. **公开领取二维码**：对应该券的通用领取入口。
    - 同一券重复打开时复用现有通用入口。

4. **领取链接**：与二维码指向同一领取入口，只读展示。

## 三、公开领取—领取与操作说明

1. **下载二维码**：下载当前入口二维码，供线上分享或线下展示。

2. **复制领取链接**：复制当前只读链接。

3. **领取校验：
    - **领取校验**：券模板为「发放中」且剩余量大于 0；若不满足，则提示对应原因。
    - **重复领取**：本期不设置每人限领；同一账号再次成功领取时生成另一张用户券，每张分别占用额度并起算有效期。
