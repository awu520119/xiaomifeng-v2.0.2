# 创建套票主题 PRD

> 版本 v1.0　·　日期 2026-11-03

*需求场景：运营人员在主题管理中创建或编辑套票主题，配置游客端展示信息、景区拍摄路线、售价和交付内容，并确保任意拍摄完成进度都有可用的成片模板。*

## 创建入口与步骤

1. **创建入口**：运营人员在「主题管理」点击「新增主题」，打开三步配置抽屉。套票主题步骤依次为「基础信息」「拍摄路线配置」「定价与交付」。

2. **主题类型**：创建表单展示「套餐主题」「玩法主题」「套票主题」；本期仅「套票主题」可选，另两种类型不可选。保存后主题类型为「套票主题」。

3. **步骤切换**：点击「下一步」时校验当前已填写内容；校验失败时停留在当前步骤并提示补齐必填项。点击「上一步」返回前一步，已填写内容保留。

4. **关闭与取消**：点击「取消」、抽屉关闭按钮或关闭抽屉时不保存当前编辑内容；已单独保存的草稿不受影响。当前表单没有未保存修改确认。

5. **存草稿**：任一步骤均可点击「存草稿」，不要求必填项全部完成；保存当前已有配置并关闭抽屉。主题名称为空时列表名称为「未命名套票主题」，未填写的价格按 0 保存，所属景区未选择时列表显示「—」。再次编辑草稿时回显已保存内容。

## 基础信息

1. **主题名称**：必填，去除首尾空格后保存，最多 24 个字符。该名称用于主题管理列表、游客端套票卡片及订单主题快照。

2. **拍摄人数**：必填，单选。当前可选「不限人数」「1人」「2人」「3人」「4人」；默认「不限人数」。该值用于游客端说明套票适用人数，不改变拍摄点数或价格。

3. **主题封面**：必填，单张图片。图片由运营人员本地选择，用于游客端主题列表卡片及主题详情首屏。当前表单不限制图片尺寸、比例或文件大小。

4. **主题标签**：必填，至少选择一个标签，可多选。标签展示在游客端主题卡片及详情中。当前原型选项为「无人值守」「正式运营」「热门」及一个测试占位项；正式创建应从主题标签字典读取可用标签。

5. **主题介绍**：必填，最多 100 个字符。由运营人员填写，用于游客端主题详情介绍。

## 拍摄路线配置

1. **所属景区**：必填，单选。拍摄点及其可用航线由所选景区决定。当前原型选项为「云湖景区」「萧山科创园」「科创机场」，来源为本地 Mock 配置。
    - 若更换已选景区，则立即清空已选拍摄点及其航线、拍摄效果、示例图片；预计时长和步行距离保留。

2. **预计体验时长**：必填，单位为分钟，整数且大于等于 1。运营人员手动填写；含义为整条路线步行、等待和拍摄的预计总时长，用于游客端路线概览。

3. **预计步行距离**：必填，单位为 km，精确到 0.1，最小值为 0.1。运营人员手动填写，用于游客端路线概览。

4. **拍摄点**：必选 2 至 5 个，点位候选项来自所选景区。每个景区中的点位只能选择一次；已选点位按选择顺序编号，该顺序作为游客端路线展示顺序。
    - 未选择景区时不展示可选点位，并提示「请先选择所属景区」。
    - 已达到 5 个时，其余未选点位不可继续选择。
    - 选择数量少于 2 个或多于 5 个时不能进入下一步或保存已发布主题。

5. **点位顺序**：每个已选点位提供「上移」「下移」。操作只调整路线顺序，不清除该点位的航线、效果说明或示例图片。

6. **取消选择点位**：取消无已填写配置的点位时立即移除；若该点位已填写航线、效果说明或上传示例图片，则先二次确认。确认后移除点位并清空该点位配置；取消确认则保留。

7. **选用航线**：每个已选点位必填单选项，候选航线来源于「所属景区 + 拍摄点」对应的可用航线配置。当前原型中的景区、点位和航线关系为本地 Mock。

8. **拍摄效果说明**：每个已选点位必填文本，由运营人员填写，用于说明该点位拍摄效果并展示在游客端。仅校验非空白，不设置长度上限。

9. **拍摄角度示例**：每个已选点位必填 1 至 6 张图片，支持多选上传。示例图片用于游客端查看该点位拍摄角度；不作为实际拍摄素材或交付媒体。当前原型未限制图片大小及分辨率。

## 定价与交付

1. **原价**：必填，人民币金额，精确到分，最小值为 0.01 元。由运营人员填写，用于游客端划线价及优惠金额展示。

2. **套票售价**：必填，人民币金额，精确到分，最小值为 0.01 元。由运营人员填写，作为主题价格及新订单的商品金额。
    - **价格关系**：原价不得低于套票售价；不满足时阻止保存并提示「原价不能低于套票售价」。
    - **优惠金额**：由原价减套票售价计算，当前表单不单独编辑优惠金额。

3. **交付内容**：至少选择一项；默认勾选「智能精剪」和「高光照片」，智能精剪默认勾选「横屏」和「竖屏」。套票可选「智能精剪」「高光照片」「原片素材」。取消某项后，该项不作为游客购买承诺展示。

4. **智能精剪画幅**：仅在勾选「智能精剪」后配置，可选「横屏」「竖屏」，至少选择一种。游客端及后续媒体交付按选择画幅提供成片。

5. **按完成点数配置默认模板**：智能精剪启用后，按完成拍摄点数为 1 至路线总点数的每一种数量配置模板；每个启用画幅均需配置。模板候选当前为「云上环绕模板」「原地转圈模板」「电影感拉升模板」「湖面穿越模板」，来源为表单内置的本地模板 Mock。完成 0 个点时不生成成片，不需要模板。
    - 若路线包含 N 个点，则需要覆盖 1 至 N 个已完成点数；同一完成点数下不同点位组合默认使用相同模板。N 个点共有 2^N−1 个非空完成组合，均由点数默认模板覆盖。
    - **特殊点位组合模板**：可为指定的非空点位组合配置专属模板；未单独配置时回退到对应完成点数的默认模板。专属组合仅影响该组合及启用画幅，不改变其他组合的默认模板。若一次完成的点位组合同时匹配点数默认配置和专属配置，则优先使用专属配置。
    - **样片替换**：默认显示所选模板的样片示意。运营人员可上传图片或视频替换该组合及画幅的样片，也可点击「恢复模板样片」还原。样片仅用于配置预览，不替代成片模板。

6. **高光照片**：游客端展示名称为「精选照片集」。当前配置区显示固定的「高光照片 × 8」及按所选航线汇总的「航线照片」数量，并可选上传一张示例照片供游客端预览；照片数量不在本表单单独编辑。

7. **原片素材**：勾选后加入游客端交付承诺。当前表单没有可配置字段，素材段数和总时长显示「—」，因来源素材统计尚未接入，不得将「—」解释为 0。

## 游客端展示映射

1. **主题卡片与详情**：主题名称、封面、标签、介绍、拍摄人数、原价、套票售价及优惠金额由本次保存的主题配置提供；优惠金额按原价减套票售价计算。

2. **路线信息**：所属景区、预计体验时长、预计步行距离、按配置顺序排列的拍摄点、各点航线、拍摄效果说明及拍摄角度示例由路线配置提供。

3. **交付说明**：游客端只展示已勾选的交付类型；智能精剪仅展示已启用画幅；高光照片显示实际计算后的照片数量；原片素材在统计数据未提供时显示「—」。特殊组合模板影响后续实际成片，不向游客增加模板配置操作。

4. **数据生效范围**：新创建订单使用下单时有效的主题配置；已创建订单按订单快照展示。当前小程序原型使用独立本地 Mock，尚未与主题管理配置联动。

## 保存、编辑与结果

1. **保存为已发布**：点击「保存」时校验必填项、拍摄点数量、每个点位的必填配置、已选交付类型、智能精剪画幅及所需模板、价格关系。通过后保存为套票主题并关闭抽屉；校验失败时停留在对应步骤并提示修正。

2. **列表字段来源**：保存后的主题管理行展示主题名称、主题类型、主题状态、标签、套票售价、原价、所属景区、创建时间和所属账号。所属景区来自本表单；创建时间取保存时系统时间；所属账号取当前后台账号。

3. **编辑既有主题**：打开编辑时回显已保存配置。保存更新该主题的基础信息、拍摄路线、价格及交付配置；不新建另一条主题。
    - 编辑草稿后点击「保存」，主题状态变为「已发布」；点击「存草稿」则保持「草稿」。
    - 编辑非草稿主题时，保存配置不改变该主题当前状态。

4. **订单快照**：主题配置更新不改写已创建订单中的主题名称、价格、拍摄路线及交付规则；新订单使用下单时有效的主题配置。游客端历史订单按下单快照展示。

5. **变更点位或画幅后的模板校验**：任何路线点数或启用画幅变化后，保存时必须重新满足所有适用的默认模板及特殊组合模板要求；失效的配置不得被静默套用。
