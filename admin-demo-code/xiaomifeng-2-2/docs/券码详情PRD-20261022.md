# 券码详情 PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：运营人员查看指定体验券编号对应的领取信息和凭证，并将未领取编号定向发给一个用户。*

## 一、券码详情—权限说明

1. **页面入口**：在「查看券码」点击编号或「详情」，查看同一张券码的详情。
    - 查看权限与券码列表一致。

2. **发放权限**：查看详情不等于取得发放授权。
    - 未领取券码的定向发放权限引用[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「权限说明」。

## 二、券码详情—详情说明

1. **体验券编号**：作为顶部主信息展示，与券码列表编号一致。

2. **券名称、券类型**：展示当前券所属模板名称与类型。

3. **使用状态**：使用与券码列表一致的状态。

4. **领取用户**：已领取展示脱敏手机号，未领取展示「未领取」。

5. **领取时间**：展示实际绑定时间，未领取展示「—」。

6. **有效期/截止时间**：展示领取后有效天数。
    - 已领取时追加具体截止时间，未领取不显示虚构截止时间。

7. **券码**：展示该张券唯一券码，支持复制。

8. **二维码**：点击「查看二维码」后展开，二维码指向当前单张券的领取入口，可下载。

9. **领取链接**：提供「复制领取链接」，与当前单券二维码对应。

## 三、券码详情—定向发放说明

1. **指定编号发放字段**：仅未领取时提供接收手机号输入及就近「发放」按钮。
    - 手机号必填，须为以 1 开头的 11 位数字，一次仅输入一个手机号。

2. **提交校验与结果**：提交时核对当前编号仍未领取、目标券可发放、额度足够且账号已授权。
    - 成功后只绑定当前编号，不替换成其他券码，并记录发放人、领取时间和截止时间。失败时保留原券码状态并提示原因。

3. **已领取边界**：已绑定用户时不再提供本页手机号发放输入，不能转发给其他用户。
    - 反复查看、复制和下载不改变券码、领取时间或截止时间。
