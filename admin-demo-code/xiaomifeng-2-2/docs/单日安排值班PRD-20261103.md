# 单日安排值班 PRD

> 版本 v1.0　·　日期 2026-11-03

*需求场景：管理员从某个日期直接安排一名人员负责一个班次，并可继续为当天添加其他不重叠班次。*

## 单日新增

1. **入口**：点击日历未安排日期打开「新增排班」；已有排班日期先查看详情，再点击「添加排班」。
2. **值班日期**：自动带入点击日期并锁定，不在本流程修改日期；如需多个日期，使用「批量排班」。
3. **值班责任人**：必选，默认不选；选项为当前在岗运维人员，展示「{姓名}（{系统账号}）」。未绑定飞书、缺少联系电话不影响选择；人员已删除或非在岗不得用于新排班。
4. **班次**：必选，默认带入班次列表第一项；展示名称及起止时间，跨天标明「次日」。
5. **负责范围**：禁用选择框默认「全部拍摄点」，本期不可修改。
6. **暂无人员**：展示「暂无在岗运维人员」及「管理运维人员」，进入管理时关闭新增弹窗；保存仍需具备有效人员。
7. **暂无班次**：展示「暂无班次」及「设置班次」，进入设置时关闭新增弹窗；不得保存缺少班次的排班。

## 冲突校验

1. **同日安排多名人员**：每次新增一名人员和一个班次，允许在同一天重复进入添加其他不重叠班次；不通过本流程直接编辑其他已有记录。
2. **时间重叠**：所选日期及班次实际起止时间不得与任一已有排班重叠，不论是否为同一责任人、是否使用同名班次。已有排班在相邻日期但跨天占用本班次时间时，同样视为冲突。
3. **时间边界**：结束时间早于开始时间时算次日结束；结束时间恰等于另一班次开始时间时不算冲突。同一人员可连续负责相接的班次。
4. **冲突反馈**：选择班次后提示当前日期是否存在该时段冲突；保存时再次校验，错误中展示冲突日期、责任人、班次和时间，保留输入，不覆盖原记录。
5. **异常输入**：责任人未选、已不可用，或班次缺失、已删除时，阻止新增，提示重新选择有效人员或班次。

## 保存与返回

1. **成功新增**：全部校验通过后新增一条排班，提示「已新增 1 天排班」，关闭新增弹窗并展示当日详情；月历同步显示最新人员、班次和时间。
2. **继续安排**：详情保留「添加排班」，管理员可继续安排当天其他班次。单条调整与删除均在详情中针对对应记录操作，不能误作用于同日其他人员。
3. **取消与关闭**：不新增记录；若进入前当天已有排班，则返回当日详情；若当天未安排，则返回日历。该新增弹窗不通过点击遮罩关闭。
4. **重复安排**：重复提交同一日期和同一班次会因已有时段冲突被阻止，不新增重复记录。
5. **通知**：新增、后续调整及删除均不发送飞书通知。

## 待确认事项

1. **多人同班**：本文件按当前原型的同一时段一条记录口径描述；是否允许不同人员同班协作，尚需业务确认。
2. **历史日期与操作权限**：过去日期能否新增排班、谁可以新增或调整，以及跨天归属是否统一采用业务所在地时区，需正式业务规则确认。
