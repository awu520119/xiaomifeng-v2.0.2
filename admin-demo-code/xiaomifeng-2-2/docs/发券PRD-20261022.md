# 发券 PRD

> 版本 v1.0　·　日期 2026-10-27

*需求场景：被授权人员在移动端发放优惠券，并查看本人发放结果。*

## 变更记录

| 版本 | 日期 | 变更内容 | 提出人 |
| --- | --- | --- | --- |
| v1.0 | 2026-10-27 | 初版；收敛发券规则 | awu |

## 一、权限

1. **权限说明**：
    - 须有「发券中心」-「可管理」权限；无权限时不可发放。
    - 仅展示当前账号有权发放的券；平台管理员、租户管理员及平台运营默认可发全部券。

## 二、券卡与入口

1. **券卡信息**：展示券名称、券类型、状态、优惠内容、剩余可发数量及领取后有效期。

2. **发放入口**：

| 券类型 | 发放方式 |
| --- | --- |
| 满减券、折扣券、特价券 | 「定向发放」「公开发放」 |
| 体验券 | 「发放体验券」自动选择单张编号后「定向发放」「扫码领取」 |

## 三、发放规则

1. **通用校验**：仅「发放中」且有剩余可发数量的券可发放；不满足时入口禁用。

2. **价格券**（满减、折扣、特价）：
    - **定向发放**：输入一个 11 位手机号；校验该用户未领取同一券模板后，绑定用户并记录当前发放账号 ID。
    - **公开发放**：创建公开入口，用户通过二维码或领取链接领取；同一用户对同一券模板仅可领取一张，定向与公开领取合并校验。公开领取不追踪发放人，展示「-」。

3. **体验券**：点击「发放体验券」后自动进入一个「未领取」编号。
    - **定向发放**：输入一个 11 位手机号，校验编号仍可发放后绑定用户并记录当前发放账号 ID；归入「定向发放」。
    - **扫码领取**：展示该编号的二维码、券码及领取链接；用户领取后归入「券码领取」，不追踪发放人，展示「-」。
