> 版本 v1.0　·　日期 2026-10-22

*需求场景：具有发券权限的工作人员在手机上查看本人获授权的券，向指定手机号发券或展示公开领取二维码。*

## 一、发券—权限说明

1. **页面入口**：「营销管理」二级导航「发券中心」，排在「优惠券记录」之后。
    - 直接使用当前登录账号，不设置独立登录或账号切换。

2. **页面权限**：具有发券中心访问权限的人员可进入。
    - 实际发放还须满足[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「权限说明」的功能权限与单券授权条件。

3. **数据范围**：「发券」仅展示当前账号获授权的券，含已暂停和已结束券。
    - 本人发放结果及领取明细见[《发放记录 PRD》](发放记录PRD-20261022.md)。

4. **权限变化**：进入页面及提交发放时按当前账号授权校验。
    - 授权撤销后不得继续发放该券，既有发放记录保留。无授权券时展示「暂无可发放优惠券」，提示联系管理员配置发券权限。

5. **页面结构**：提供「发券」「发放记录」两个主入口，适配手机单列阅读和触控。
    - 三类券名称、标签颜色及模板状态引用[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「状态与计算口径」，用户券状态引用[《券使用记录 PRD》](券使用记录PRD-20261022.md)「使用状态说明」。

## 二、发券—发券列表说明

### 一、筛选与排列

1. **查询**：授权券超过 3 张时提供券名称搜索框，按名称包含关键词匹配，支持清空。
    - 无匹配时展示「没有找到匹配的优惠券」。

2. **排列**：可发放券排在前，已暂停或已结束券保留可见但禁用发放操作。
    - 页面不增加统计报表。

### 二、券卡字段

1. **券名称**：展示已保存券名称，长名称允许换行。

2. **券类型**：展示「满减券」「折扣券」「体验券」，标签颜色与后台优惠券列表一致。

3. **发放状态**：展示「发放中」「已暂停」「已结束」，计算规则与后台管理一致，不使用「可发放」「已发完」替代。

4. **优惠内容**：展示该券已保存规则对应的优惠摘要。

5. **剩余数量**：当前共用总量中尚可发放的数量，单位张。
    - 发放或领取成功后更新。

6. **有效期**：展示「领取后 {有效天数} 天」。

7. **适用范围**：展示适用拍摄点和主题，未限制范围时展示全部适用。

8. **使用规则**：展示已保存的使用规则，默认收起。
    - 点击标题展开完整内容，再次点击收起。
    - 历史缺失时展示「暂无使用规则」。

9. **操作**：并列「定向发放」「公开领取」，三类券均支持。
    - 仅有权限且状态为「发放中」时可操作。

10. **折叠规则**：展开使用规则不改变当前所选券或发放方式。
    - 完整内容保留换行，不因篇幅长截断为不可查看的内容。

## 三、发券—定向发放说明

### 一、页面与表单字段

1. **页面进入**：点击券卡「定向发放」，打开该券的手机发放页面。
    - 返回后回到券列表。

2. **券名称**：只读，自动带出所选券名称。

3. **券类型、发放状态**：只读标签，与券列表同一类型及模板状态。

4. **优惠内容**：只读，自动带出该券优惠摘要。

5. **有效期**：只读，展示领取后有效天数，提交成功后据此确定截止时间。

6. **剩余数量**：只读，展示该券当前剩余可发张数。

7. **适用范围**：只读，自动带出该券拍摄点与主题。

8. **使用规则**：可展开只读，同「发券列表说明」中的使用规则展开与收起方式。

9. **接收用户手机号**：必填输入，每次仅输入一个以 1 开头的 11 位数字手机号，调起数字输入键盘。
    - 号码不完整或格式错误时提示「请输入正确的 11 位手机号」。

### 二、提交与结果

1. **确认发放**：点击「确认发放」时再次校验授权、券模板状态和至少一张剩余额度。
    - 校验失败保留当前页并提示原因，不创建部分发放结果。提交处理中按钮不可重复提交同一笔发放。

2. **体验券分配**：从当前券未绑定编号中分配一张给目标手机号，与后台使用同一券池。
    - 实际绑定后起算有效期。

3. **成功页字段**：展示「发放成功」、接收手机号、券名称、券类型、当前用户券状态、领取后有效天数、具体截止时间以及券码。
    - 体验券展示对应体验券编号。券码或编号支持复制。

4. **成功后动作**：「继续发券」返回券列表。
    - 「查看发放记录」进入本人记录。成功发放同步出现在后台「定向发放记录」及「券使用记录」。

## 四、发券—公开领取说明

### 一、入口与详情字段

1. **页面进入**：在券卡点击「公开领取」，为本次发放建立归属当前账号的领取入口，用于后续追踪领取情况。
    - 创建入口不等于实际发出用户券，不扣减领取额度。

2. **适用类型**：满减券、折扣券、体验券均可公开领取。
    - 入口沿用券总量、发放状态和领取后有效天数，不另配置入口数量、限领、固定有效期或单独截止时间。

3. **创建结果**：成功后展示「公开领取入口已创建」。

4. **券名称**：展示本次公开领取的券名称。

5. **券类型、发放状态**：与后台优惠券管理当前模板一致。

6. **公开领取二维码**：对应本人的当前领取入口。
    - 用户扫码后以当前小程序账号确认领取，券进入本人券包；体验券权益同时到账。

7. **有效期**：展示「领取后 {有效天数} 天可用」。

8. **可领取数量**：展示该券当前共用剩余发放量，不表示给当前入口单独分配的额度。

9. **使用规则**：使用与券卡相同的完整规则，可展开和收起。

### 二、领取与操作

1. **领取成功**：价格券领取时分配独立用户券码，体验券使用现有未绑定券码。
    - 记录手机号、领取时间和具体截止时间，并计入该入口领取明细和后台券使用记录。

2. **本页操作**：提供「下载二维码」和「查看发放记录」。
    - 发券中心不提供「复制领取链接」或「停用入口」。二维码未就绪时下载失败并提示重试，下载本身不增加领取数量。

3. **停发影响**：优惠券在后台被暂停或额度用尽后限制新领取，已有用户券继续保留其领取信息与截止时间。
    - 类型和状态展示使用同一管理口径。
