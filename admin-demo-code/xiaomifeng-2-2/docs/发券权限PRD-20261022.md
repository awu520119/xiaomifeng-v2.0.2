## 一、发券权限

1. **打开入口**：在优惠券列表的单张优惠券操作中选择「发券权限」，打开「发券权限」弹窗。
    - 弹窗展示优惠券名称和券类型。

2. **授权账号**：多选可发放该券的账号，选项展示「账号（姓名）」。
    - 无授权账号时，保存后该券不可由其他账号发放；平台管理员和超级管理员仍按系统权限规则处理。

3. **发放校验**：
    - 账号须同时具有系统「发券」功能权限和该券的发券权限，才可发放该券。
    - 权限被撤销后，已发放的用户券不受影响；该账号不能继续发放该券。
