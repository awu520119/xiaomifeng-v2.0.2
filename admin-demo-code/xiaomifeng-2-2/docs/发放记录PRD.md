## 页面与查询

1. **范围**：仅展示已绑定用户的实际券，包括满减券、折扣券及体验券；自动备码但尚未绑定的券不展示。不设置 Tab，不提供发券入口。
2. **筛选**：输入手机号查询、发放日期区间、状态；重置清空三项筛选，不提供发放方式筛选。
3. **字段**：券名称、券类型、状态、领取用户、关联订单号、发放方式、有效期、操作；发放方式展示定向发放、公开领取或券码领取。
4. **订单关联**：展示当前占用订单、使用订单或活动发券时填写的关联订单；未关联显示「—」。
5. **状态**：保留价格券待使用、待支付占用、已核销等状态，以及体验券待核销、权益已到账、部分使用、已用完等状态；有效期及作废状态同步更新。
6. **作废**：操作列仅保留作废。未用完且未锁定的券可确认作废，保留历史且不返额度；已核销到账的体验权益不通过此操作撤回，不可作废的记录显示禁用按钮。
7. **上下文**：从券详情或本次批次进入时保留限定范围，可查看全部记录；筛选重置不退出范围。
8. **演示数据**：保留体验券定向和券码领取样例，覆盖待核销、权益到账、部分使用、已用完和作废，旧浏览器数据仅补充一次样例。
