## 订单列表

1. **订单类型**：套票订单展示为「套票订单」，并可通过现有订单类型筛选项单独筛选。

2. **拍摄点**：套票订单展示所属景区及拍摄点数量；拍摄点筛选匹配套票路线中的任意点位，命中后整笔订单展示一次。

3. **拍摄进度**：展示已完成点位数与路线总点位数，例如「1/2 点」。进度按订单快照中状态为「已完成」的点位数量计算；单点订单在该列显示「—」。

4. **订单状态**：支付成功且尚未开始拍摄为「待使用」；任一点位开始拍摄后为「已使用」，全部点位拍摄成功且约定媒体交付完成后为「已完成」。退款发起后为「退款中」，成功后为「已退款」；退款失败恢复退款前状态。拍摄进度单独展示。

5. **金额与统计**：订单列表金额使用该笔订单的下单金额快照。订单数及金额汇总按订单统计；一笔套票包含多个拍摄点时不得按点位重复计数。

6. **导出**：套票订单导出时保留订单类型、所属景区、拍摄点数量及拍摄进度；同一订单只导出一行。

## 订单详情

1. **订单信息**：沿用现有订单信息区展示订单号、订单状态、订单类型、用户、手机号、订单时间、支付金额及支付方式。套票订单类型展示为「套票订单」。

2. **主题信息**：展示主题名称、拍摄人数、剪辑模板、主题介绍案、套餐名称及拍摄进度。缺失字段显示「—」。主题名称、路线和交付配置以订单创建时的快照为准，不随主题后续修改而变化。

3. **拍摄路线与点位状态**：按下单时的路线顺序展示套票包含的 2–5 个拍摄点。每个点位展示名称、航线、拍摄效果、拍摄状态、完成时间及起飞任务 ID；尚未生成的完成时间或任务 ID 显示「—」；同一点位可能因拍摄失败等原因产生多个起飞任务 ID，逐条以链接按钮展示，点击查看对应任务详情；无任务时显示「—」。
    - **异常点位**：拍摄失败不计入已完成点位数；用户可在失败点位无限次重新拍摄，每次保留独立起飞任务 ID。取消或提前结束的状态及处理仍待确认。

4. **媒体交付展示条件**：若订单尚无已生成媒体，则不展示媒体交付区。订单详情不单独展示「交付内容」分节。

5. **媒体交付版本**：每次生成成片形成独立版本，保留已生成版本，不覆盖历史版本。媒体交付区默认展示最新版本，并允许切换查看历史版本。
    - **版本信息**：每个版本展示版本号、生成时间、该版覆盖的拍摄点、使用模板及媒体数量。
    - **版本媒体**：只展示所选版本实际包含的媒体，可按媒体类型查看横屏或竖屏精剪、精选照片及原视频；数量按所选版本展示。
    - **部分完成**：若部分拍摄点已完成并已生成媒体，则展示媒体交付区及对应版本；尚未生成的内容不混入当前版本。
    - **全部完成**：展示完整交付内容及最新版本；历史版本仍可切换查看。
    - **媒体生成中或失败**：若媒体正在生成或生成失败，当前状态、失败后的展示方式及是否提供重新生成操作待确认。
    - **重复生成**：同一批拍摄点再次生成媒体时是否形成新版本、版本排序及其与原版本的关系待确认；确认前不得覆盖既有版本。
    - **媒体预览**：媒体缺失、无法播放或无法加载时的占位状态，以及预览失败后的可用操作待确认。

6. **流程日志**：按时间顺序记录订单生成、支付、各拍摄点完成、每次成片生成、套票交付完成及退款等已有事件。成片生成日志能够对应到相应版本。

7. **退款规则**：仅支持整单全额退款，不支持按拍摄点部分退款。订单未完成且没有拍摄任务进行时，用户可自行申请退款；部分点位已完成或媒体生成中也可申请。拍摄进行中不可申请；订单已完成后不可自行退款。无需人工审核。
    - **确认信息**：提交前展示全部实付金额、优惠券按原有效期返还、剩余拍摄权益终止及已有媒体保留。
    - **处理结果**：退款中暂停拍摄及重试；成功后退还全部实付金额、返还已使用优惠券并终止剩余拍摄权益。返还优惠券沿用原有效期，已过期仍为过期。已生成媒体与历史任务保留。
    - **退款失败**：恢复退款前订单状态及点位进度，用户可继续拍摄或重新申请退款。
