> 版本 v1.0　·　日期 2026-10-22

*需求场景：获授权的运营人员通过手机号将指定价格券发放给目标用户，并核对整批发放结果。*

## 一、定向发放—权限说明

1. **页面入口**：后台优惠券列表的满减券或折扣券「发放」中选择「定向发放」，打开居中弹窗。
    - 体验券指定编号发放见[《券码详情 PRD》](券码详情PRD-20261022.md)。

2. **权限与券状态**：发放权限引用[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「权限说明」。
    - 只有「发放中」且剩余量足够的券可发放，提交时再次校验。

## 二、定向发放—表单字段说明

1. **优惠券**：只读，自动带出所选券名称。

2. **券类型**：只读标签，自动带出满减券或折扣券。

3. **接收手机号**：多行输入，必填，输入 11 位、以 1 开头的手机号。
    - 多个手机号可使用换行、空格、英文或中文逗号、分号分隔。

4. **重复号码**：按输入条数逐张发券，不对重复手机号去重。
    - 相同手机号输入两次即发放两张，并占用两张额度。

## 三、定向发放—提交与结果说明

1. **整批校验**：点击「确认发放」时校验整批输入和当前发放条件。
    - **手机号**：至少输入一个有效号码，且全部号码格式正确。
    - **发放条件**：账号已获授权，券可发放，输入条数不超过剩余量。
    - **校验失败**：任一项不满足时整批不发放，保留输入并提示原因。

2. **确认与结果**：点击「确认发放」并成功后，每张券绑定对应手机号，记录发放时间、当前发放人和截止时间。
    - 同批结果可在「定向发放记录」查看，用户券状态进入「券使用记录」。

3. **关闭**：点击「关闭」或关闭弹窗时结束当前发放填写，不生成发放记录。
