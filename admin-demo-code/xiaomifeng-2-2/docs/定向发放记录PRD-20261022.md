## 一、定向发放记录—权限说明

1. **页面入口**：在「优惠券记录」中切换到「定向发放记录」页签，须具有对应记录查看权限。

2. **记录范围**：一条记录代表一张成功定向发放到账的用户券。
    - 同一手机号多张券逐张展示。公开领取、券码领取及独立体验权益到账事件不进入本列表。

3. **用途边界**：本页追溯发放结果，不展示或筛选用户券使用状态。
    - 当前使用状态在「券使用记录」查询。本页不提供发券或核销入口。

## 二、定向发放记录—筛选项说明

1. **券名称、手机号**：关键词输入，按券名称或接收用户手机号包含关键词匹配，支持清空。

2. **发放时间**：日期范围，以成功定向发放时间查询，包含开始日和结束日全天，支持清空。

3. **查询与重置**：各项共同生效。
    - 筛选变化或查询时回到第 1 页。
    - 点击「重置」清空条件。不提供发放方式筛选，因为本列表只包含定向发放。

## 三、定向发放记录—列表说明

1. **字段顺序**：发放人在券类型之前，创建一条发放结果时记录对应发放人员。

2. **序号**：按分页连续编号。

3. **券名称**：展示发放券名称。

4. **发放人**：主要展示发放账号，姓名在账号下方辅助展示。
    - 沿用发放时记录的人员身份。

5. **券类型**：与优惠券列表相同的类型标签。

6. **体验券编号**：体验券展示独立「TY-」连续编号，为纯文本，不提供详情点击。
    - 价格券展示「—」。

7. **接收用户**：展示接收用户脱敏手机号。

8. **发放时间**：成功发放到账时间，精确到分钟。
    - 历史缺失时展示「—」。

9. **关联订单**：有关联订单时展示完整内容入口及复制操作，无订单展示「—」。

10. **排序与分页**：按发放时间倒序。
    - 默认每页 20 条，支持切换页码与每页条数，展示总条数。
    - 无匹配数据时展示「暂无符合条件的定向发放记录」。

11. **记录保留**：用户券后续使用、退款、过期或作废不删除已发生的定向发放记录。
    - 本列表不增加「操作人」或其他与发放人重复的字段。
