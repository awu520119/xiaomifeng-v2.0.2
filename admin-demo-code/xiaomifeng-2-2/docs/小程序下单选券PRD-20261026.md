# 小程序下单选券 PRD

> 版本 v1.0　·　日期 2026-10-25

*需求场景：用户选定套餐后确认金额，并按需使用优惠券完成下单或支付。*

## 变更记录

| 版本 | 日期 | 变更内容 | 提出人 |
| --- | --- | --- | --- |
| v1.0 | 2026-10-26 | 初版 | awu |

## 一、确认订单

1. **入口**：
    - 选定套餐/确定下单后进入。

2. **展示金额**：
    - 展示商品金额、优惠金额和应付金额。应付金额为商品金额减优惠金额，最低为 0。

3. **无可用券**：
    - 保留确认订单页，优惠金额为 0，仅展示「暂无可用优惠券」，直接按商品金额提交。


## 二、选择优惠券（可选）

1. **打开选券**：展示可用券数量，点击后打开「选择优惠券」弹层。
    - 仅展示当前用户持有、未使用、未作废、未过期且适用于当前套餐的券；
    - 价格券还须满足使用门槛，体验券每张只能兑换一次体验。

2. **选择逻辑**：默认选中优惠金额最高的一张，用户可改选或选择「不使用优惠券」；价格券与体验权益不能叠加。

3. **金额更新**：选择后即时更新优惠金额和应付金额；满减、折扣按券配置计算，优惠金额不超过商品金额。

## 三、提交订单

1. **提交校验**：提交时再次校验所选券；失败时提示「所选优惠券已不可用，请重新选择」，不生成订单。
