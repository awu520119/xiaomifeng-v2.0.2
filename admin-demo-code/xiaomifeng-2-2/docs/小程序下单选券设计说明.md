# 小程序下单选券设计说明

## 页面结构

从作品详情的套餐选择进入确认订单。页面展示所选套餐及拍摄点、可切换的主题或套餐、优惠券入口、商品金额、优惠金额和应付金额。点击优惠券入口，从底部弹出单选列表，不离开订单上下文。

可用券按本单优惠额排列，默认推荐优惠最大的券；用户可选择另一张或「不使用优惠券」。不可用券折叠展示具体原因。选择后即时更新订单金额，提交时再次校验券状态。

价格券提交订单后进入订单详情的待支付状态；在那里确认支付后记录实际优惠。体验券订单无需支付，直接进入待拍摄状态。

体验券权益适用于当前拍摄内容时，与价格券同列但明确标识为体验权益。下单后预占一次体验权益，完成体验服务后计入实际使用。
