> 版本 v1.0　·　日期 2026-10-25

*需求场景：用户选定拍摄套餐后，查看可用优惠券并确认优惠后的支付金额。*

## 页面结构

1. **页面入口**：从「商品详情与选购」的套餐选择弹层进入「确认订单」，带入已选套餐。
    - 本页展示套餐、拍摄点与金额，不再提供主题或套餐切换。

2. **金额信息**：展示「商品金额」「优惠金额」「应付金额」，金额单位为元，保留两位小数。
    - 商品金额取已选套餐价格；应付金额为商品金额减去本次优惠金额，最低为 0。
    - 底部展示可用优惠券数量、已减金额、应付金额及提交按钮。

## 优惠券选择

1. **打开选券**：点击底部优惠券入口，打开「选择优惠券」弹层。

2. **可用券**：展示当前用户持有且适用于所选套餐的价格券及体验权益。
    - 价格券须未使用、未作废、未过期、未被其他待支付订单占用，并满足使用门槛和适用范围。
    - 体验权益须在有效期内、有剩余次数且适用于所选套餐。

3. **推荐与单选**：可用券按本单优惠金额从高到低排列，未指定选择时默认选中优惠最大的券。
    - 用户可改选一张或选择「不使用优惠券」，价格券与体验权益不能叠加。

4. **优惠计算**：满减券优惠取配置的减免金额；折扣券优惠为商品金额 ×（1 − 折扣 ÷ 10），四舍五入保留两位小数。
    - 优惠金额不超过商品金额；选择体验权益时，本单优惠等于商品金额。

5. **不可用券**：在「不可用优惠券」折叠区展示不可用价格券及原因，不允许选中。

6. **选择反馈**：选择后即时更新订单金额，弹层底部展示「已选 {数量} 张」「已减 ¥{优惠金额}」及「确定」。
    - 点击「确定」关闭弹层；选择「不使用优惠券」时，数量和优惠金额均为 0。

## 提交与结果

1. **提交校验**：提交时再次校验所选券或体验权益。
    - 若所选券已不可用，则提示「所选优惠券已不可用，请重新选择」，不完成本次下单支付。

2. **价格券或无券订单**：应付金额大于 0 时，按钮为「确认支付」；成功后进入订单详情，订单展示「待拍摄」，价格券记录本单实际使用结果。

3. **体验权益订单**：应付金额为 0 时，按钮为「确认下单」；成功后直接进入「待拍摄」，预占一次体验权益。
    - 完成体验服务后计入实际使用，不因权益到账就标记为「已使用」。

4. **订单详情**：下单成功后展示内容及后续操作见[小程序订单详情 PRD](小程序订单详情PRD-20261022.md)。
