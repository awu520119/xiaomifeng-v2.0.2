> 版本 v1.0　·　日期 2026-10-25

*需求场景：用户通过输入或扫描体验券兑换码，将对应体验券领取到本人券包。*

## 页面入口

1. **券包入口**：从「我的券包」的「待使用」页签底部点击「兑换优惠券」，进入「兑换体验券」。

2. **券码入口**：通过单张体验券二维码或领取链接进入时，带入对应兑换码。
    - 兑换码仅用于体验券，不兑换满减券或折扣券。

## 兑换操作

1. **页面封面**：展示通用优惠券封面。

2. **兑换码输入**：提供输入框与扫码入口，输入框提示「请输入体验券兑换码」。
    - 普通券包入口不预填兑换码；修改输入后清除上次查询结果与错误提示。
    - 不提供独立「查询」按钮。

3. **扫码**：点击扫码图标打开相机预览。
    - 若无法调用相机或用户未授权，则提示原因，并允许手动输入。
    - 本期仅支持通过「使用演示券码」填码，不支持实际二维码识别。

4. **立即兑换**：点击「立即兑换」核对兑换码；若不存在对应体验券，则提示「兑换码不存在，请检查后重试」。

5. **二次确认**：有效兑换码打开「确认兑换」弹窗，以券卡展示体验权益、券名称、券类型及领取后有效天数。
    - 点击「取消」关闭且不领取；点击「确认兑换」提交领取。

## 兑换结果

1. **提交校验**：确认时核对当前账号手机号、券码归属、券码状态、模板发放状态与剩余量。
    - 若已被他人领取、券码已失效、模板已暂停或已领完，则提示对应原因，不新增用户券或体验权益。

2. **兑换成功**：当前券码绑定本人，按领取时间与有效天数确定截止时间，体验权益同步到账。
    - 展示「兑换成功」，点击「查看我的券包」进入[券包](小程序券包PRD-20261022.md)。

3. **本人重复兑换**：若该券码已由本人领取，则展示「已在券包中」，提供查看券包操作。
    - 不新增券、不重复占用额度、不重算有效期。
