# 小程序兑换页 PRD

> 版本 v1.0　·　日期 2026-10-25

*需求场景：用户通过体验券券码领取体验券并获得对应体验权益。*

## 变更记录

| 版本 | 日期 | 变更内容 | 提出人 |
| --- | --- | --- | --- |
| v1.0 | 2026-10-25 | 初版 | 用户 |

## 一、进入兑换页

1. **进入方式**：
    - 从「我的」页面的「优惠券」入口进入「我的券包」，再从「待使用」页签点击「兑换优惠券」。

2. **领取来源**：兑换码仅用于体验券；保留发放人 ID。

## 二、输入与确认

1. **输入兑换码**：
    - 手动输入或点击扫码入口打开相机预览。
    - 无法调用相机时提示原因，并允许手动输入。

2. **确认兑换**：点击「立即兑换」校验兑换码。
    - **兑换码不存在时**：提示「兑换码不存在，请检查后重试」。
    - **校验成功时**：展示确认弹窗，包含体验权益、券名称、类型和领取后有效天数。
    - 点击「取消」不领取；点击「确认兑换」提交。

## 三、兑换结果

1. **提交校验**：确认时校验当前账号手机号、券码归属、券码状态、模板状态和剩余量。
    - **校验失败时**：已被他人领取、券码失效、模板暂停或已领完时，不新增用户券和体验权益，并提示原因。

2. **兑换成功时**：将券码绑定当前用户，按兑换时间起算有效期并到账体验权益。
    - 一个兑换码只能绑定一张体验券，每张体验券只能兑换一次体验。
    - 用户券、兑换记录和券使用记录保留券码对应的发放人 ID。
    - 展示「兑换成功」，提供「查看我的券包」。

3. **本人重复兑换时**：展示「已在券包中」，提供查看券包。
