## 页面结构

1. **页面入口**：从「我的」点击「优惠券」，或从领取、兑换结果点击「查看我的券包」进入。

2. **数据范围**：仅展示当前用户已领取或定向发放到账的券，不展示未领取券码。

3. **状态页签**：提供「待使用」「使用中」「已失效」，默认「待使用」，各页签展示对应数量。
    - 「已失效」收纳「已使用」「已使用（退款）」「已过期」「已作废」，券卡仍展示具体状态。
    - 状态含义见[券使用记录 PRD](券使用记录PRD-20261022.md)。

4. **排列**：「待使用」按截止时间从近到远排列；其他页签按获取时间从新到旧排列。

5. **空态**：当前页签无券时展示「暂无{页签名称}的券」，提示可通过领取链接、二维码或兑换码获取。

## 券卡与操作

1. **券卡字段**：展示优惠权益、券类型、当前状态、券名称及实际有效期信息。
    - 有效期展示具体截止时间；适用范围仅在详情中查看。

2. **使用规则**：券卡底部提供默认收起的「使用规则」，展开后展示完整内容，再次点击收起，箭头随展开状态变化。

3. **查看详情**：点击券卡打开[详情弹层](小程序券详情PRD-20261022.md)，不进入独立页面。
    - 「已失效」券仍可点击券卡查看详情，不另设「查看详情」按钮。

4. **去使用**：仅「待使用」券提供；本期点击后提示「去使用将跳转到首页」，不直接进入下单。

5. **兑换优惠券**：仅在「待使用」页签内容底部固定展示，点击进入[兑换页](小程序兑换页PRD-20261022.md)。
