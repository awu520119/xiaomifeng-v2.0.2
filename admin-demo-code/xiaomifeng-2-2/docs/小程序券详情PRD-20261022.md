## 页面结构

1. **打开方式**：点击[券包](小程序券包PRD-20261022.md)券卡打开底部详情弹层，不设置独立页面。

2. **券名称**：弹层标题展示所选券名称。

3. **优惠内容**：展示该张券对应的满减、折扣或体验权益摘要。

4. **有效期**：已领取券展示实际领取时间至截止时间，精确到分钟。
    - 若没有领取时间，则展示「领取后 {有效天数} 天可用」。

5. **适用范围**：展示该券适用拍摄点及主题；未限制的范围展示全部适用含义。

6. **使用规则**：展示优惠条件、适用拍摄点和主题限制及每笔订单只能选择一张优惠券的说明。
    - 长文本完整展示，可滚动阅读。

## 操作说明

1. **关闭**：点击关闭按钮或弹层外遮罩，返回当前券包。

2. **去使用**：仅「待使用」券展示；点击关闭详情并提示「去使用将跳转到首页」，本期不直接进入下单。
