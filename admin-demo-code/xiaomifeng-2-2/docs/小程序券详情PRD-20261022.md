## 一、查看券详情

1. **打开详情**：在「我的券包」中点击券卡打开底部详情弹层，不进入独立页面。

2. **查看信息**：展示券名称、优惠内容、有效期、适用范围和使用规则。
    - 已领取券：展示实际领取时间至截止时间。
    - 使用规则：按配置带出。

## 二、操作

1. **去使用**：仅「待使用」券展示；点击后关闭详情，并按适用范围跳转：
    - **适用范围为全部**：跳转到首页。
    - **多个适用拍摄点属于同一景区**，跳转到该景区首页。
    - **适用范围为一个拍摄点**：跳转到该拍摄点页面。
    - **适用范围为一个主题时**：跳转到该主题详情页。
