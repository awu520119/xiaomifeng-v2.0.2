# 小程序商品详情与选购设计说明

## 页面结构

保留参考系统的场景封面、作品标题与热度、创作者信息、智能精剪视频、精选照片、原片素材及底部价格与「选套餐」。图片为项目内演示素材，不依赖远程服务。

选套餐使用底部弹层和横向套餐卡；卡片展示名称、价格和包含内容，点击卡片单选，确认后进入确认订单。确认订单在同一流程内展示套餐、拍摄点、优惠券入口和金额明细；用户选择一张可用券后即时更新优惠金额和应付金额。

提交后进入订单详情，展示订单状态、套餐、拍摄点、订单信息、使用优惠、优惠金额及支付金额。待支付订单可取消或立即支付，取消会释放占用券，支付后订单进入待拍摄。三段页面不再作为独立导航或查看器目录项，而是同一条「商品详情与选购」流程中的连续状态。
