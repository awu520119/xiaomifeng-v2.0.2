## 一、订单信息

1. **使用优惠券**：：
    - 展示对应使用的优惠券名称（优惠券类型）；未使用时展示「未使用优惠券」。

2. **优惠金额**：展示该订单实际优惠金额。

3. **实付金额**：展示订单实际支付金额。

4. **退款与返券**：
    - 体验券全额退款后返还原用户；券仍在有效期内时恢复「待使用」。
    - 价格券（满减、折扣、特价）退款未返券时保持「已使用」，退款及返券结果在订单或使用记录中查看。
