## 页面入口

1. **页面入口**：通过[公开领取](公开领取PRD-20261022.md)链接或二维码进入对应优惠券的领取页。
    - 单张体验券兑换码进入[兑换页](小程序兑换页PRD-20261022.md)。

2. **领取身份**：使用当前小程序账号领取，不在页面展示账号信息或提供账号切换。

## 页面内容与操作

1. **券卡**：顶部优惠提示区下展示券卡，包含优惠权益、券名称、券类型、「可领取」标签及「领取后 {有效天数} 天有效」。
    - 「可领取」为领取前展示标签，最终结果以提交时校验为准。

2. **使用规则**：券卡底部默认收起，点击展开，再次点击收起。
    - 展示该券优惠摘要及仅限适用拍摄点和主题使用的说明。

3. **券详情**：点击券卡打开详情弹层，展示「优惠内容」「有效期」「适用范围」「使用规则」，关闭后返回领取页。
    - 领取前展示领取后有效天数，不生成具体截止时间。

4. **领取操作**：点击底部「立即领取」提交；打开详情或展开规则不执行领取。

## 领取结果

1. **领取校验**：提交时核对当前账号手机号、入口是否存在且有效、券模板发放状态及剩余量。
    - 若入口存在领取名单限制，则同时核对当前账号是否在名单内。
    - 校验失败展示原因，不新增用户券、不扣减额度。

2. **领取成功**：券绑定本人并进入券包，按本次领取时间加有效天数确定截止时间。
    - 体验券同步获得可下单的体验权益。
    - 展示「领取成功」，点击「查看我的券包」进入[券包](小程序券包PRD-20261022.md)。

3. **入口不可用**：无法取得对应优惠券时，展示「领取入口不可用」，提示获取新的领取链接或二维码，并提供「查看我的券包」。
