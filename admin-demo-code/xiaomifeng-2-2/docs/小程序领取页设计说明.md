# 小程序领取页设计说明

## 目标与入口

用户点击公开领取链接或扫描其二维码，进入同一张领取页。页面根据入口对应的优惠券展示内容，不设置领券中心。

## 信息顺序

1. 优惠内容与券名称。
2. 适用拍摄点、主题及领取后有效天数。
3. 简短使用说明。
4. 底部固定「立即领取」。

领取成功后在本页展示结果，提供「查看我的券包」。入口不存在、已停用、已领完或不在领取名单时，展示明确原因。体验券领取后权益直接到账，可在符合条件的订单使用。

## 演示说明

查看器默认使用演示账号 `13800000001` 和满减券公开领取入口；正式领取链接以 `planId` 指定入口。后台与用户端共用本地 Mock。
