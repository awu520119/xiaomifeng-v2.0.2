## 页面与状态

1. **用户与筛选**：演示手机号查询持券及权益，券按待使用、已使用/兑换、已过期、已作废及全部筛选。
2. **价格券**：展示规则、期限与状态；待支付占用时说明占用，其他可用券提供「去使用」。
3. **体验券**：未核销显示「待核销」并提供「出示兑换码」，弹窗展示单券二维码与可复制券码，工作人员通过活动发券确认后到账；不直接进入价格券下单。
4. **账户体验权益**：展示可用次数、已体验次数、总次数、适用商品、原券截止时间；可用时提供「去体验」，过期或用完时不可新建订单。
5. **详情**：查看券码、优惠内容、范围、生效/截止时间及状态。有效期与统计口径引用《优惠券体系PRD.md》。
