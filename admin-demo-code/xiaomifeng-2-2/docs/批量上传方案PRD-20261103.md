> 版本 v1.0　·　日期 2026-11-03

*需求场景：使用方按统一模板批量导入处置方案，定位错误并在全部内容通过校验后一次加入方案库。*

## 上传入口与模板

1. **入口**：从方案库点击「批量上传」，打开「按模板批量上传方案」窗口；本入口批量上传的是方案资料，不是附件文件。
2. **下载模板**：点击「下载模板」下载「处置方案导入模板.csv」，包含表头及示例行。填写时可替换示例行；保留的示例行会作为普通方案参与导入。
3. **表头顺序**：按以下六列填写，不得调整名称或顺序：「方案名称」「设备类型」「故障类型」「故障现象或者错误提示信息」「可能原因」「处置步骤」。
4. **行规则**：每个有效数据行对应一个方案；完全空白的行不参与导入。文本中需要包含英文逗号、换行或双引号时，按CSV格式使用引号包裹并正确转义。
5. **选择文件**：点击「选择 CSV 文件」，选择填写完成的CSV；取消文件选择不导入，关闭窗口不修改方案库。

## 字段与校验

1. **方案名称**：必填，导入时去除首尾空格。
2. **设备类型**：必填且只能为「机场」「无人机」「机场和无人机」，按去除首尾空格后的完整值校验。
3. **故障类型**：必填，导入时去除首尾空格。
4. **故障现象及可能原因**：选填，未填写时保存为空，详情显示「—」。
5. **处置步骤**：必填，多个步骤使用中文分号「；」分隔，去除每步首尾空格并忽略空分段；按填写顺序生成步骤。
6. **附件及关键词**：当前模板不包含附件、匹配关键词或版本列；导入不自动上传附件、不自动建立附件关联。需要时导入后进入编辑补充。

## 错误反馈与导入结果

1. **表头错误**：若列名或顺序与模板不一致，则提示「表头与模板不一致」，不导入任何方案。
2. **无数据**：若只有表头或没有有效数据行，则提示「文件中没有方案」，不新增记录。
3. **行内容错误**：存在必填缺失或设备类型不正确时，提示「第 {行号} 行缺少必填项或设备类型不正确」，本次全部不导入，保留原有方案；当前反馈首个错误数据行供修正后重新选择文件。
4. **格式异常**：CSV引号不闭合时提示「CSV 引号未闭合」；其他读取或解析失败应说明失败，不能显示导入成功。
5. **成功结果**：全部数据校验通过后，一次加入所有方案，关闭上传窗口，提示「已导入 {数量} 个方案」；新增方案在列表前部展示，文件内行顺序保持一致，当前查询条件仍生效。
6. **初始信息**：导入方案初始版本为「V1.0」，更新时间为导入时间；修改人按当前演示为「系统管理员」。后续编辑适用编辑方案的保存规则。
7. **失败后重试**：修正CSV后重新选择文件，重新校验全批；失败批次不留下部分已导入方案。

## 待确认事项

1. **列数与额外列**：当前原型校验模板要求的列，未严格拒绝多余列；正式是否严格限定六列，待确认。
2. **行号口径**：当前按忽略空白行后的数据位置提示行号；包含空行或多行单元格时是否改为文件实际行号，需确认。
3. **重复导入**：当前重复名称或重复上传不阻止新增，正式是否去重、覆盖或提示重复方案，待确认。
4. **完整校验**：导入名称80字限制与新建表单的统一、仅有分号而无有效步骤、文件大小和导入条数上限，当前未明确，待确认。
