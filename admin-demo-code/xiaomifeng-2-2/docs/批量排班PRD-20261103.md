## 批量排班配置

1. **入口**：点击日历顶部「批量排班」，打开右侧抽屉。抽屉正文独立滚动，「取消」「保存排班」固定在底部；选中日期较多时仍能访问保存操作。
2. **值班责任人**：必选，初始为空，仅选择运维人员中在岗人员；选项展示「{姓名}（{系统账号}）」，不是飞书账号。未绑定飞书或无联系电话不影响排班选择；账号缺失时明确显示「账号未配置」。
3. **班次**：必选，带入当前班次列表第一项；选项展示班次名称及完整起止时间，跨天标识「次日」。已删除班次不进入新增选项。
4. **负责范围**：展示禁用选择框「全部拍摄点」，本期不可修改。
5. **前置数据不足**：
    - 若没有在岗人员，则展示「暂无在岗运维人员」及「管理运维人员」；进入管理前关闭排班抽屉。
    - 若没有班次，则展示「暂无班次」及「设置班次」；进入设置前关闭排班抽屉。
    - 人员或班次未满足必填条件时不得保存；再次打开时使用已保存的最新人员和班次配置。

## 日期选择

1. **初始状态**：进入时不默认选择日期；显示当前日历选中日期所在月份。
2. **多选方式**：支持逐日点选、再次点击取消选中，以及鼠标拖选连续日期；跨月切换保留已选日期。
3. **周快捷选择**：提供「{月日}所在周工作日」和「所在周全部」。锚点日期在当前显示月份时，以该锚点所在周为准；切换到其他月份后，以该月一日所在周为准。工作日仅指周一至周五，不涉及节假日调休。
4. **选择结果**：展示「已选 {天数} 天」、已选日期标签及「清空」；标签可逐个移除。同一日期重复选择或通过不同方式加入时只计算一次。
5. **冲突标记**：根据当前选中班次，标记与已有排班实际时间重叠的日期，包括跨天影响的相邻日期。改变班次后重新判断冲突。
6. **冲突处理**：冲突日期可被选中，但需在选择结果中列明并阻止保存；不自动跳过或覆盖已有排班。管理员可取消相关日期或改选其他班次。

## 保存与退出

1. **必填校验**：责任人、班次和至少一个值班日期均须具备；人员须仍为在岗状态，班次须仍有效。
2. **重叠规则**：同一天允许多班次，所选班次与已有记录不能有时间重叠；相接边界不算重叠。已存在同日其他不重叠班次时允许保存。
3. **批量校验**：保存前检查全部日期及本次新增记录之间的重叠；若任一日期冲突，则本批次全部不保存，保留输入并提示冲突对象，供管理员调整后重新提交。
4. **保存成功**：每个日期新增一条对应人员及班次的排班，提示「已新增 {天数} 天排班」，关闭抽屉；日历切换到所选日期中最早日期所在月份并选中该日期。已有排班不被替换。
5. **取消与遮罩关闭**：点击「取消」、关闭按钮或抽屉外遮罩均关闭抽屉且不新增记录；再次打开不沿用未保存日期和人员选择。
6. **通知**：保存结果不发送飞书通知。
