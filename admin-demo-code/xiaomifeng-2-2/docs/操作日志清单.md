# 操作日志清单

来源：[平台操作日志.mm](../平台操作日志.mm)、[租户操作日志.mm](../租户操作日志.mm)。本清单逐项定义原型列表中的**操作模块、操作类型、操作内容**。每一行是一种操作，不是某一条实际日志；操作时间和操作人账号由实际记录填充。`{}` 是运行时变量，正式展示时不显示花括号。

## 展示规则

- 操作内容统一为「动作「对象」；关键结果或实际变化」。`{字段名}：{修改前} → {修改后}` 只展示实际发生变化的字段；多个字段以「；」连接，不展示未改动字段。新增时只展示必要初始信息，删除时展示被删除对象，不编造前后值。
- 本清单中的「位置」用于确认后台和页面；列表的「操作模块」显示对应二级导航业务模块。操作人账号、时间、来源后台和对象 ID 随日志保存。平台跨租户操作且对象名称没有体现租户时，内容末尾补「；作用租户：{租户名称}」。
- 密码、应用密钥、收款账户等敏感值不显示明文；可写「已重置」「已更新」或脱敏后的账号末四位。二维码重新生成只记录动作，不展示二维码内容。
- 对下发、升级、返航、重试等异步操作，记录当前发生的动作（如「发起」「下发」）；不能仅凭点击就写「升级成功」「返航完成」。同一操作的执行结果如需追踪，应由任务记录或单独的结果事件提供。
- 「操作类型」统一为新增、编辑、删除、执行四类：新建、导入或上传形成的新对象归「新增」；修改已有对象的配置、状态、权限及审批结论、作废状态归「编辑」；删除对象归「删除」；发放、退款、导出、下发、返航、重试、重置等其他业务动作归「执行」。具体动作仍在「操作内容」中写明。以下内容是待确认的记录口径，不表示现网已经接入。
