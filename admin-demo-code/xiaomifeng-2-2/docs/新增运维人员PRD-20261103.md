# 新增运维人员 PRD

> 版本 v1.0　·　日期 2026-11-03

*需求场景：管理员从已有系统账号选择人员，通过手机号查找并核对飞书身份后加入运维人员列表。*

## 选择系统账号

1. **入口**：从「运维人员管理」点击「新增运维人员」。本期新增流程为选择账号、查找飞书身份、核对并确认绑定。
2. **用户账号**：仅选择已有系统账号，不在此新建账号；选项展示「{姓名}（{系统账号}）」，支持搜索。已加入运维人员的账号不再提供重复添加。
3. **无可选账号**：展示「暂无可添加的用户账号」，不能继续查找或确认绑定。
4. **手机号带入**：选择账号后展示该账号关联的系统手机号，按脱敏方式展示；缺失时显示「未配置」。手机号来源必须与该账号一致，不能展示其他人员的号码。
5. **切换账号**：重新选择账号时清空上一账号的匹配结果和错误提示，按新账号重新查找，不允许把前一账号的飞书身份保存给新账号。

## 查找与核对飞书身份

1. **主动查找**：点击「查找飞书账号」发起查找。尚未选择账号时提示「请先选择系统账号」。
2. **手机号缺失**：提示「该账号未配置手机号，请先完善系统账号信息」，不生成匹配结果，不允许确认绑定。
3. **未找到匹配**：账号有手机号但未匹配飞书身份时，提示「未找到匹配的飞书账号，请核对手机号或联系管理员」，保留当前账号供核对，不把该情况表述为未配置手机号。
4. **匹配成功**：展示「请核对是否为同一人，确认后完成绑定」，并展示系统账号、系统手机号、飞书姓名及飞书用户标识。系统账号与飞书身份必须有清楚标签区分。
5. **确认状态**：没有匹配结果时「确认绑定」不可用；匹配成功仅表示可核对，仍须管理员确认，不自动加入运维人员。

## 确认与退出

1. **重复校验**：确认时再次检查系统账号仍存在且尚未加入运维人员；若已加入或不存在，则阻止保存。若飞书身份已绑定其他人员，则提示「该飞书账号已被其他运维人员绑定」。
2. **保存结果**：确认后将所选系统账号对应人员加入运维人员列表，带入姓名、系统账号、联系电话及核对后的飞书身份；初始为在岗、已绑定，默认负责范围「全部拍摄点」。
3. **联动**：保存成功后关闭新增弹窗并刷新人员列表；该人员可在后续排班中选择，提示「飞书账号绑定成功」。
4. **取消与关闭**：未确认前取消或关闭，不新增运维人员、不写入绑定关系；再次进入清空此前未完成选择及匹配结果。
5. **姓名重复**：添加资格以系统账号判断，不能仅因姓名相同阻止添加；核对时使用系统账号和手机号区分。

## 待确认事项

1. **无手机号人员的新增方式**：已有无联系电话的运维人员可以排班，但当前新增流程要求先通过手机号查找并绑定；是否允许先添加未绑定人员，或通过其他方式匹配飞书，需确认。
2. **账号及绑定权限**：可管理的系统账号范围、可操作的管理员角色，以及查找失败、权限不足等真实飞书异常处理尚未定义，不能将演示可见账号视为正式授权范围。
