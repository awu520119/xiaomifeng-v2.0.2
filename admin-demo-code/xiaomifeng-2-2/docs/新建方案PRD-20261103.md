## 入口及表单

1. **新建入口**：从方案库点击「新建方案」，打开「新建处置方案」抽屉；表单使用占位文字说明各项填写内容，占位内容不是实际默认值。
2. **编辑入口**：从列表「编辑」或详情「编辑方案」打开同一表单，标题为「编辑处置方案」；带入当前方案字段、关键词、步骤和已关联附件。
3. **方案名称**：必填，最多80个字符；占位「请输入方案名称，例如：机场网络中断处置方案」。
4. **适用设备类型**：必选，选项为「机场」「无人机」「机场和无人机」；新建默认「机场」，编辑带入原值；未选择时提示选择设备类型。
5. **故障类型**：必填文本；占位「请输入故障类型，例如：网络异常」。
6. **匹配关键词**：选填，提示多个关键词使用中文逗号分隔；保存时同时识别中文、英文逗号，空分段不作为关键词。编辑时将已保存关键词带入，允许修改或清空。
7. **故障现象或者错误提示信息**：选填多行文本，占位说明填写故障表现或设备提示。
8. **可能原因**：选填多行文本，占位说明填写可能原因。
9. **处置步骤**：必填多行文本，提示「每行一个步骤」；保存后按输入行顺序形成步骤，忽略空行及每步首尾空格；详情按顺序编号。
10. **未提供字段**：当前表单不要求填写方案状态、型号、错误码或注意事项，不将历史数据字段作为新增必填项。

## 相关附件

1. **选择已有附件**：附件选填，支持多选；未选择时展示「选择已有附件」，已选择时展示「已选择 {数量} 个附件」及下方「已选附件」清单。同一文件不重复关联到当前方案。
2. **移除关联**：在选择框中取消某文件，保存后仅解除当前方案的该文件关联；不删除文件，不影响其他方案。
3. **上传并关联附件**：支持JPG、JPEG、PNG、DOC、DOCX、PDF；上传成功后文件加入附件管理，并加入当前表单的已选附件。上传失败时提示失败，不加入当前选择，允许重新选择文件。
4. **预览与下载**：点击已选文件名称预览；右侧独立下载入口保持可见。图片及PDF可预览；Word显示下载查看提示；缺失内容显示「文件内容不可用」并禁用下载。
5. **上传与保存关系**：文件上传成功即进入附件管理，当前方案的关联须保存方案后生效。若上传后取消表单，新文件保留在附件管理，未曾保存到其他方案的文件为「未关联」。
6. **查看返回**：关闭文件预览返回当前表单，保留未提交的文本及已选附件。

## 保存与取消

1. **保存入口**：底部提供「取消」「保存并生成版本」，操作区与表单正文分开，长表单滚动时仍可操作。
2. **表单校验**：名称、设备类型、故障类型、处置步骤缺失时不保存，保留已填内容供修正；其他选填项可为空，不因缺少附件阻止保存。
3. **新建结果**：保存成功后新增方案，初始版本「V1.0」，记录本次更新时间及修改人，关闭表单并提示「方案已创建」；列表显示最新字段及附件数量。
4. **编辑结果**：保存后更新当前方案及更新时间，版本递增，提示「方案已保存并生成新版本」；已打开详情同步显示保存内容。当前原型每次提交编辑均递增版本，尚无历史版本查看或回退入口。
5. **取消与关闭**：点击「取消」或关闭抽屉，不保存表单字段及关联修改；已上传文件按前述规则保留。重新进入新建时不沿用上次未保存内容，进入编辑时重新带入已保存内容。

## 待确认事项

1. **同名文件处理**：原型按文件名处理文件，同名上传会替换文件内容并影响引用该名称的其他方案；正式规则是否覆盖、重命名或拒绝，待确认。
2. **版本规则**：原型从「V1.0」开始按数值增加0.1，需确认正式版本的进位规则，以及无实际修改时是否生成版本。
3. **空白与重复内容**：方案重名、纯空白名称或故障类型、仅含空行的处置步骤是否拒绝，当前校验未完整覆盖，正式规则待确认；不将这些输入描述为可正常使用的方案。
4. **文件限制**：附件数量、单文件大小及总大小上限尚未明确；当前演示存储容量不足时提示上传失败，不作为正式容量标准。
