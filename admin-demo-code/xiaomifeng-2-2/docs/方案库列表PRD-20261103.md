## 查询与结果列表

1. **查询条件**：提供方案名称或故障提示搜索、设备类型、故障类型，可组合使用；多个条件同时存在时须全部满足。
2. **关键字**：去除输入首尾空格后，对方案名称、故障现象或者错误提示信息进行包含匹配，忽略英文大小写；输入为空时不限制关键字。当前原型输入变化即更新结果，搜索按钮及回车亦可使用。
3. **设备类型**：可选「机场」「无人机」「机场和无人机」，可清空。
    - 选择「机场」时返回适用「机场」或「机场和无人机」的方案。
    - 选择「无人机」时返回适用「无人机」或「机场和无人机」的方案。
    - 选择「机场和无人机」时仅返回该类型方案。
4. **故障类型**：选项来自已有方案的故障类型，去重展示；选择后精确匹配，可清空。
5. **重置与无结果**：点击「重置」清空上述条件；若没有符合条件的方案，则展示「暂无匹配方案」，保留查询及新建入口。
6. **列表字段**：展示方案名称、适用设备类型、故障类型、版本及修改人、附件数量、更新时间和操作。
    - 方案名称可点击查看详情；名称下展示匹配关键词，若没有关键词则展示故障类型。
    - 当前演示中缺少版本、修改人的历史方案分别显示「V1.0」「系统管理员」，不表示存在可查询的历史版本。
    - 附件数量取当前方案已保存的关联数量，未关联附件不计入。
7. **分页**：默认每页10条，可选10、20、50条，并展示结果总数。查询结果、附件弹窗和方案操作均应对应当前方案，不能因翻页操作到其他方案。
8. **新增与导入后的展示**：新建和批量上传的方案加入列表前部，当前筛选条件继续生效；若新增方案不符合当前条件，则不在当前结果中展示。编辑不主动改变该方案的列表顺序。

## 附件快捷查看

1. **无附件**：附件列展示「0 个」，不提供点击操作。
2. **有附件**：展示「{数量} 个」，文字位置与无附件行对齐；点击后打开「相关附件」，不要求先进入方案详情。
3. **文件操作**：每条展示文件图标、完整名称及独立下载入口；长文件名可换行，不挤压下载入口。点击文件名打开预览；关闭预览后仍可返回该方案的附件清单。
4. **预览规则**：JPG、JPEG、PNG按图片预览，PDF按文档预览；DOC、DOCX提示浏览器不支持直接预览并提供下载。文件内容缺失时显示「文件内容不可用」，下载不可用，预览中说明需上传同名文件后查看。
5. **数据联动**：方案保存附件关联后更新数量；附件管理删除文件后，所有关联方案的附件数量和清单同步减少。关闭附件窗口不改变方案。

## 方案管理操作

1. **入口**：顶部提供「新建方案」「批量上传」「附件管理（{数量}）」；附件管理数量为管理范围内去重的文件数量，不是列表中各方案附件数之和。
2. **编辑**：行内「编辑」打开当前方案编辑抽屉，带入已保存内容；保存后更新列表及已打开详情，取消不改变方案内容。
3. **删除方案**：点击「删除」后提示「确认删除该处置方案？」及「删除方案不会删除附件管理中的文件。」，提供「删除」「取消」。
4. **删除结果**：确认后仅移除目标方案并提示「处置方案已删除」；取消不改变记录。若该方案详情已打开，则关闭其详情。附件文件保留，其关联处置方案信息重新按剩余方案计算；不再关联任何方案的文件显示「未关联」。
