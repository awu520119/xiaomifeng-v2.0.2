> 版本 v1.0　·　日期 2026-11-03

## 进入与信息展示

1. **列表入口**：点击方案库的方案名称，在当前页面右侧打开「处置方案详情」，保留原列表查询条件及上下文。
2. **告警入口**：从告警推荐方案进入对应详情，展示同一份已保存内容；关闭后返回原告警上下文。不同入口不生成独立的方案副本。
3. **基础信息**：展示方案名称、适用设备、故障类型及最近更新时间，均来自当前已保存方案。
4. **故障现象或者错误提示信息**：展示完整文本；未填写显示「—」。
5. **可能原因**：展示完整文本；未填写显示「—」。
6. **处置步骤**：按保存顺序逐条展示「步骤 {序号}」及内容，从1开始；空行不作为独立步骤。
7. **字段边界**：当前详情不展示独立状态、型号、错误码、注意事项或历史版本回退操作；列表中的版本及修改人不视为详情已具备对应功能。

## 相关附件

1. **无附件**：展示「暂无附件」，不提供无对象的预览下载操作。
2. **有附件**：按当前方案关联展示文件图标、文件名及下载入口；文件名可换行，点击名称预览，下载入口独立可操作。
3. **预览内容**：图片按图片展示、PDF按文档展示；Word提供不支持直接预览提示和下载。关闭预览返回当前方案详情，不改变关联。
4. **文件内容缺失**：名称保留并提示「文件内容不可用」，下载禁用；预览说明需上传同名文件补齐，不把该情况显示为「暂无附件」。
5. **联动更新**：在方案编辑保存后，详情更新为新关联清单；附件管理删除文件后，该方案的对应关联同步消失。删除方案不删除其附件文件。

## 编辑与关闭

1. **编辑方案**：方案库详情底部提供「编辑方案」，打开当前方案的编辑表单，带入已保存字段及附件；是否展示入口以当前来源页面实际提供的管理能力为准，不要求告警只读入口额外具备编辑能力。
2. **保存结果**：编辑成功后更新当前方案内容、版本和更新时间，关闭编辑抽屉；若详情仍打开，则同步展示保存结果。
3. **取消编辑**：取消或关闭编辑，不更新方案文本、步骤和关联；已经上传的附件仍留在附件管理。
4. **关闭详情**：关闭后恢复原列表或告警上下文，不清空原查询条件、不修改方案。
5. **当前方案删除**：若从方案库删除正在查看的方案，则关闭该详情；对应附件文件保留。

## 待确认事项

1. **失效入口**：携带方案定位信息进入时，若方案已删除或不可访问，当前原型不打开详情；正式是否展示「方案不存在或已删除」并提供返回入口，待确认。
2. **历史引用**：告警中的方案引用应显示当前版本还是告警发生时的版本、删除方案后历史引用如何保留，尚未明确。
