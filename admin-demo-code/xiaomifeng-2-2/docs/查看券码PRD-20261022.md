# 查看券码 PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：运营人员查询体验券逐张券码的领取及使用情况，并导出未领取券码用于线下发放。*

## 变更记录

| 版本 | 日期 | 变更内容 | 提出人 |
| --- | --- | --- | --- |
| v1.0 | 2026-10-22 | 初版 | awu |

## 一、查看券码—权限说明

1. **权限控制**：
    - 须具有「营销管理」下「优惠券管理」的「发放」功能权限。
    - 须有该券的「发券权限」。

## 二、查看券码—筛选项说明

1. **搜索体验券编号、手机号**：按体验券编号或领取用户手机号包含关键词匹配，支持清空。

2. **券码使用状态**：单选，包括待使用、使用中、已使用、已使用（退款）、已过期、已作废、未领取。

## 三、查看券码—列表说明

1. **体验券编号**：展示当前独立编号，点击打开「券码详情」。
    - 按全局连续序号生成，格式为 TY- 加 6 位数字，例如 TY-000001、TY-000002

2. **使用状态**：未绑定用户时展示「未领取」。

| 状态 | 业务含义与触发条件 |
| --- | --- |
| 「待使用」 | 已领取，仍有效，未被订单占用且尚未完成该券对应使用；体验权益到账本身不表示已完成服务 |
| 「使用中」 | 价格券被待支付订单占用；或体验券已创建体验订单但尚未完成服务 |
| 「已使用」 | 价格券已经用于成功支付；或体验券已完成对应体验服务 |
| 「已使用（退款）」 | 已使用的价格券发生退款且不满足返还条件，券保持使用终态 |
| 「已过期」 | 未作废、未完成使用且未被订单占用，并已超过单券截止时间，不可继续使用 |
| 「已作废」 | 人工执行作废成功，不可继续使用 |

3. **领取用户**：已领取展示脱敏手机号，未领取展示「未领取」。

4. **领取时间**：展示实际领取或定向发放到账时间。
    - 未领取展示「—」。

5. **发放人 ID**：已投放或已领取的编号关联对应发放人 ID；未投放编号不产生发放人 ID。

6. **有效期**：统一展示领取后的有效天数。
    - 未领取仅展示「领取后 {有效天数} 天有效」。
    - 已领取追加展示「截止时间：{具体截止时间}」。

## 四、查看券码—导出说明

1. **导出可领取券码**：展示可导出未领取券码数量。
    - 没有可导出券码时禁用。
    - 点击后将当前体验券全部可领取券码打包为压缩包，包含券码清单、逐张二维码图片和对应领取链接。
    - 券码清单、二维码及领取链接中包含对应发放人 ID；未投放编号导出时不预设发放人 ID，实际投放后再绑定当前发放账号。

2. **导出结果**：导出过程不绑定用户、不启动有效期、不改变发放额度。
    - 导出失败时展示失败原因并允许重试。
