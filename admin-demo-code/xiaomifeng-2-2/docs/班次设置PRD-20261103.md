> 版本 v1.0　·　日期 2026-11-03

*需求场景：管理员维护排班可用的班次名称和起止时间，并删除不再使用的班次。*

## 班次配置

1. **入口与回显**：点击「班次设置」打开配置弹窗，展示当前已保存班次；初始演示班次为「早班」08:00–16:00、「晚班」16:00–次日00:00。
2. **字段**：每条包含班次名称、开始时间、结束时间及「删除」，不提供启用、停用状态。
3. **添加上限**：最多添加 5 个班次；达到上限时禁用「添加班次」，提示「已达到 5 个班次上限」。删除草稿中的班次后，数量低于上限时可继续添加。
4. **新行默认值**：点击「添加班次」新增可编辑行，默认名称为「班次{当前行数加一}」、开始时间08:00、结束时间16:00；默认名称同样接受重复校验。
5. **名称校验**：保存时忽略名称首尾空格，名称不能为空、班次之间不能重名；不满足时不保存，保留当前输入并提示「班次名称不能为空或重复」。
6. **时间校验**：开始、结束时间均须填写，二者不能相同；不满足时不保存并提示「请填写有效的开始和结束时间，二者不能相同」。结束早于开始时视为次日结束，并明确标注。
7. **时间重叠**：当前允许配置时间重叠的不同班次；是否能实际排入某日，由新增、调整排班时与已有排班的时间重叠校验决定。

## 删除、保存及取消

1. **删除班次**：点击行内「删除」，提示「删除此班次？」及「保存设置后生效，已有排班不受影响。」；确认仅从当前待保存配置中移除，取消保持该行。
2. **保存设置**：全部字段校验通过后保存整组配置，关闭弹窗，提示「班次设置已保存，已有排班保持原时间」。再次打开应回显保存结果。
3. **取消配置**：点击「取消」或关闭弹窗，丢弃本次新增、编辑及删除结果；再次打开回显此前已保存配置。
4. **全部删除**：允许保存空班次列表，后续新增排班显示「暂无班次」并提供「设置班次」入口；不能使用缺失班次完成新增排班。
5. **已有排班**：修改班次名称、时间或删除班次，不批量改写已有排班。查看已有排班仍使用原班次及原时间；调整时可保留原选项，或选择其他当前班次。
6. **历史超限配置**：已有超过5个班次的配置不自动删减；禁止继续添加，允许编辑、删除及保存；降至5个以下后按上限规则操作。
7. **旧启停状态**：旧演示数据中保留的班次不再区分启停，均作为当前可选班次；管理员可直接删除不再需要的班次。
