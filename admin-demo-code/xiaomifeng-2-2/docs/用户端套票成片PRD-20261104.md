## 套票成片

1. **进入与返回**：订单已有交付媒体时，用户可从订单详情进入作品页；返回时回到原订单详情。部分点位完成且已生成媒体时可进入；退款成功后，退款前已生成媒体仍可查看。

2. **页面结构**：采用与现有小程序成片页一致的沉浸式媒体查看形式，提供媒体展示区域、媒体类型切换和返回入口。评价、分享、下载入口按现有成片页呈现；其具体处理规则待确认。

3. **媒体类型**：按所选版本实际交付的内容展示对应媒体类型，包括智能精剪、照片及原片素材；横屏或竖屏精剪按实际交付展示。未生成的媒体不计入该版本，也不应作为已交付内容展示。
    - **视频**：可播放、暂停及使用播放进度控制；可用的画幅和视频数量以该版本实际交付为准。
    - **照片**：可查看所选版本已交付的照片；照片数量按该版本实际内容展示。

4. **成片版本**：不同拍摄进度生成的媒体保留为独立版本，不能覆盖已生成的历史版本；默认查看最新版本。
    - **版本切换**：存在多个版本时，用户可切换历史版本；展示所选版本的生成时间及覆盖的拍摄点，媒体内容随版本切换。
    - **部分点位**：用户主动发起制作后，若部分点位已完成并生成媒体，作为阶段作品查看，仅展示该版本实际覆盖点位和已有媒体；用户仍可继续拍摄剩余点位。
    - **全部完成**：全部点位拍完并由用户主动发起制作，交付完整作品后默认展示最新版本，阶段作品等历史版本仍可查看。
    - **退款后**：仍可查看退款前已生成的版本和媒体；退款不新增媒体，也不清除历史版本。

5. **无交付媒体**：订单没有已交付媒体时，订单详情不提供作品查看入口；拍摄完成后用户确认制作，媒体尚在生成时详情展示生成状态，订单尚未完成；拍摄完成不会自动生成作品。

## 待确认事项

| 序号 | 待确认事项 | 涉及页面 | 状态 |
| --- | --- | --- | --- |
| 1 | 媒体生成失败、长时间生成、缺失、无法播放或加载失败的提示及可用操作 | 订单详情、套票成片 | 待确认 |
| 2 | 对同一批点位再次生成媒体是否形成新版本、版本排序及与历史版本的关系 | 套票成片 | 待确认 |
| 3 | 各交付类型在用户端的最终名称、实际可用画幅及照片浏览方式 | 套票成片 | 待确认 |
| 4 | 评价、分享、下载的可用条件、操作结果及失败处理 | 套票成片 | 待确认 |
| 5 | 零媒体、部分媒体生成失败或某类媒体缺失时是否允许订单完成 | 订单详情、套票成片 | 待确认 |
