# 用户端套票拍摄与作品制作 PRD

> 版本 v1.0　·　日期 2026-11-04

## 多点拍摄

1. **开始拍摄**：用户从订单详情进入拍摄，在拍摄点扫码识别当前点位并确认后开始拍摄。原型为便于演示跳过真实扫码；实际扫码识别及校验不能由演示结果替代。
2. **拍摄顺序**：用户无需手动调整路线顺序；按现场扫码识别的点位进行拍摄，记录实际拍摄先后。订单配置的点位用于展示和核对。
3. **状态与进度**：支付后尚未开始拍摄的订单为「待使用」；任一点位开始拍摄后为「已使用」。拍摄点分别展示「待拍摄」「拍摄中」「拍摄失败」「已完成」；成功的点位计入完成数量，同一点多次拍摄任务不重复计数。
4. **拍摄中**：同一订单已有拍摄任务进行时，不允许再次发起拍摄或申请退款；页面提示当前拍摄进度。
5. **失败与重试**：拍摄失败不计为点位完成；用户可对失败点位再次拍摄，重试次数不设上限。同一点位的多次起飞任务分别保留记录，已完成的其他点位进度不受影响。
6. **点位衔接**：完成一个点位后展示完成进度；未完成全部点位时用户可继续拍摄，或主动发起阶段作品制作。上传与剪辑的状态提示不应把拍摄完成表述为作品已经生成。

## 作品制作

1. **用户发起**：至少一个点位拍摄成功后，用户可选择「结束拍摄并制作」；拍摄完成不自动开始剪辑。确认前提示「已拍摄 {已完成点位数} 个点位。拍完整条路线，作品更有故事感。现在制作后仍可继续拍摄。」；取消则返回订单详情，不发起制作。
2. **阶段作品**：部分点位完成时确认制作，按已完成点位生成阶段作品；作品就绪后用户可查看，订单仍为「已使用」，仍可继续拍摄剩余点位。
3. **完整作品**：全部点位拍摄成功后提供「开始制作」；确认提示作品制作预计约 5 分钟。用户确认后开始制作，作品交付完成后订单变为「已完成」。
4. **制作进度**：发起制作后展示作品制作中及预计约 5 分钟的提示，用户可返回订单查看结果。作品尚未交付时，不作为已生成作品提供查看。
5. **版本保留**：阶段作品与后续完整作品各自保留；新作品生成后可查看最新作品和历史版本，版本展示实际覆盖点位。
6. **退款影响**：订单尚未完成且没有拍摄任务进行时，用户可按订单详情的规则申请整单全额退款；退款处理中不能继续拍摄或重试，退款成功后剩余拍摄权益终止，已有作品保留。
