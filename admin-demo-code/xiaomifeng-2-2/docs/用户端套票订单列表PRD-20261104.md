## 订单列表

1. **入口与范围**：用户从小程序「我的订单」进入订单列表。套票订单与其他订单在同一列表中展示；本 PRD 仅定义套票订单的展示和操作。

2. **筛选**：提供「全部」「待支付」「待使用」「已使用」「退款/取消」页签，默认展示「全部」。
    - 「待支付」展示待支付套票订单；「待使用」展示支付成功且尚未开始拍摄的订单，卡片状态显示「待使用」。
    - 「已使用」展示至少开始过一次拍摄但尚未完成的订单，以及已完成订单；卡片显示对应的「已使用」或「已完成」。
    - 「退款/取消」展示退款中、已退款及已取消订单，卡片区分对应状态。
    - 选择页签后仅展示符合该页签的订单；无符合条件的订单时展示空状态。

3. **套票卡片**：展示订单号、状态、封面、明显区别于套餐的「多点套票」标识、主题名称、拍摄点、拍摄进度及订单金额。拍摄点较多时可简要展示，完整路线在订单详情中查看。
    - **拍摄进度**：展示已完成点位数和订单包含的总点位数，例如「已完成 1/2 个拍摄点」。按点位计算，仅拍摄成功的点位计入已完成数；同一拍摄点多次任务不重复计数。
    - **失败提示**：若存在拍摄失败的点位，卡片提示存在失败，具体点位及操作在订单详情中展示。
    - **金额**：展示订单实付金额；优惠券及优惠金额在详情中查看。

4. **进入详情**：点击套票卡片进入该订单详情；返回列表后保留当前筛选，并展示最新订单状态与拍摄进度。

5. **状态口径**：支付成功且没有点位开始拍摄时为「待使用」；任一点位开始拍摄后为「已使用」；全部点位拍摄成功、用户发起完整作品制作且约定媒体交付完成后为「已完成」；部分点位制作阶段作品后仍为「已使用」，可继续拍摄。申请退款后为「退款中」，成功后为「已退款」；失败后恢复退款前状态。拍摄和交付的具体状态在详情中展示。
