## 订单详情

1. **入口**：从订单列表点击套票订单进入详情；返回时回到原列表。下单成功后也可进入该订单详情。

2. **状态与进度**：订单整体状态和每个拍摄点状态分别展示。
    - **待支付**：订单尚未支付。
    - **待使用**：支付成功且没有拍摄点开始拍摄，订单状态显示「待使用」。
    - **已使用**：任一拍摄点已开始拍摄，且订单尚未完成；按实际情况提示拍摄中、部分完成、拍摄失败或成片生成中。
    - **已完成**：全部拍摄点拍摄成功，用户发起完整作品制作且约定媒体交付完成。
    - **退款中 / 已退款**：分别展示退款处理及成功状态；未付款取消的订单展示「已取消」。
    - **进度计算**：按订单路线中的拍摄点统计「已完成点位数 / 总点位数」；只有拍摄成功的点位计入，多次起飞任务不重复计数。

3. **商品摘要**：展示套票封面、类型标识、主题名称、实付金额和拍摄点数量。主题、路线及约定交付内容以订单创建时的记录为准。

4. **拍摄点**：展示订单包含的各拍摄点名称和状态，包括「待拍摄」「拍摄中」「拍摄失败」「已完成」。
    - **进度展示**：标题右侧显示「已完成 {已完成点位数}/{总点位数}」，进度条按相同口径展示完成比例。
    - **路线与状态**：点位按订单展示顺序编号并通过连线串联；编号表示展示顺序，用户实际拍摄的点位由扫码识别。点位名称和状态同行展示，状态分别以灰、橙、红、绿区分，并保留状态文字。
    - **失败提示**：点位为「拍摄失败」时，名称下方显示「可重新拍摄」。
    - **点位操作**：展示「导航」和「电话」入口；存在联系电话时点击「电话」发起拨号，缺少联系电话时提示「暂未提供联系电话」。
    - **开始与重试**：用户可继续拍摄未完成点位；失败点位可继续拍摄，重试次数不设上限；拍摄点由现场扫码识别，用户无需手动调整顺序。
    - **进行中**：已有拍摄任务进行时，不允许重复发起拍摄或重试，也不允许申请退款；提示用户等待本次拍摄结束。
    - **失败记录**：同一拍摄点的多次起飞任务分别保留记录；失败不会使该点计入完成进度。
    - **部分完成**：其他点位未完成或失败时，保留已完成点位进度和已有媒体，用户可继续拍摄或在符合退款条件时申请退款。

5. **订单信息**：展示订单类型「套票订单」、订单号、订单时间、手机号、使用优惠券、优惠金额和实付金额；未使用优惠券时展示「未使用」，优惠金额为零时展示「¥0.00」。有完成时间时展示完成时间。

6. **作品入口**：已有媒体交付时提供「前往查看」，进入套票成片页；部分完成或退款后已有媒体仍可查看。订单详情不展示「已交付、版本及包含点位」摘要行。无已交付媒体时不提供作品查看入口。

7. **退款入口与条件**：仅支持用户自行申请整单全额退款，无需人工审核；不支持按拍摄点部分退款。
    - 支付成功、订单尚未完成且没有拍摄任务进行时可申请，包括部分点位已完成、拍摄失败以及全部拍摄完成但媒体仍在生成的情况。
    - 拍摄进行中不可申请；订单已完成后不允许用户自行退款；退款中和已退款订单不可重复申请。

8. **退款确认**：提交前展示全部实付金额、已使用优惠券按原有效期返还、退款后剩余拍摄权益终止、已生成媒体继续保留。用户确认后发起退款；取消确认则留在订单详情，不改变订单及拍摄进度。

9. **退款处理**：退款中暂停所有未完成点位的拍摄和重试。
    - **成功**：退还本单全部实付金额，返还已使用优惠券并终止剩余拍摄权益；已生成的媒体及历史拍摄记录保留。返还的优惠券沿用原有效期，返还时若已过期则仍为过期状态。
    - **失败**：恢复退款前订单状态和各点位进度，用户可继续拍摄、重试或重新申请退款。

10. **作品制作与拍摄衔接**：至少完成一个拍摄点后，用户可继续拍摄，也可主动选择「结束拍摄并制作」。确认后生成已完成点位的阶段作品；阶段作品完成后订单仍为「已使用」，用户可查看并继续拍摄剩余点位。
    - 全部点位完成后展示主按钮「开始制作」，用户确认后制作完整作品；作品制作中提示预计约 5 分钟。作品交付完成后订单变为「已完成」。
    - 订单状态展示与后台一致；「拍摄中」「拍摄失败」「作品制作中」用于说明履约进度，不作为订单状态。
    - 部分点位提前制作时提示「已拍摄 {已完成点位数} 个点位。拍完整条路线，作品更有故事感。现在制作后仍可继续拍摄。」；全部点位完成时提示「作品制作预计需要约 5 分钟。」。取消确认不发起制作。
