## 购买与订单创建

1. **购买入口**：在套票主题详情点击「立即体验」发起购买。现有原型直接生成演示订单并进入订单详情，未展示真实支付或优惠券选择流程；此演示路径不作为实际支付成功规则。
2. **价格与优惠**：订单记录套票价格、使用优惠券、优惠金额和实付金额；未使用优惠券时展示「未使用」，优惠金额为零时展示「¥0.00」。优惠券选择、适用规则和计算以确认后的购买流程为准。
3. **支付与订单**：订单未支付时状态为「待支付」；支付成功且尚未开始拍摄时状态为「待使用」。订单应记录购买时的套票主题、拍摄点及交付内容，用于订单详情回显。
4. **订单详情**：支付成功后用户可进入对应订单详情；订单可在「我的订单」中查看。
