> 版本 v1.0　·　日期 2026-11-04

*需求场景：用户浏览景区时识别多点套票，并在购买前了解套票内容、拍摄路线和作品效果。*

## 景区详情

1. **景区介绍**：展示景区封面、名称和介绍文案；介绍支持「展开」和「收起」。
2. **内容分类**：提供「单点旅拍」和「多点套票」切换，当前分类有选中样式；本 PRD 仅说明套票展示。
3. **套票列表**：选择「多点套票」后显示当前景区可展示的套票，并提示「一次解锁多个拍摄点」。卡片展示主题封面、「多点套票」标识、套票名称、拍摄点数量、点位名称摘要和价格；点位超过两个时展示前两个名称及「等」。
4. **进入详情**：点击套票卡片进入对应套票主题详情；返回景区详情继续浏览。

## 套票主题详情

1. **主题内容**：展示主题名称、套票标识和拍摄点数量；按主题配置展示智能精剪、精选照片及原片素材等交付内容。配置了视频样片或拍摄角度示例图时，支持查看对应内容。
2. **拍摄路线**：展示拍摄点数量、预计时长和路线距离；按主题配置展示各点位名称、出片效果说明及角度示例图。预计时长和路线距离缺失时显示「—」。
3. **点位信息**：展示可取得的营业状态、营业时间、当前距离和联系电话，并提供「导航」「电话」入口；信息缺失时不作为有效信息展示。点位展示顺序来自套票主题配置，用户无需手动调整拍摄顺序。
4. **购买入口**：底部展示套票价格及「立即体验」，进入套票购买与订单创建流程。
