# 订单详情（优惠券） PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：运营人员查看套餐订单详情时，需要直接确认该订单用了什么券，以及该券为这笔订单优惠了多少金额。*

## 一、订单详情（优惠券）—权限说明

1. **页面入口**：在「订单管理」的「订单列表」点击「详情」，进入当前套餐订单详情。

2. **权限**：沿用当前订单详情的查看权限。
    - 有订单查看权限即可查看该订单实际优惠信息，不额外要求取得对应券的发放授权。

3. **本期范围**：订单类型只保留「套餐订单」。
    - 优惠券信息作为「订单信息」中的只读「优惠信息」字段展示，不新增优惠券操作、表单或独立状态区。

## 二、订单详情（优惠券）—详情字段说明

1. **优惠信息**：下列内容合并展示为一条「优惠信息」，用于回答使用券名称及实际优惠金额。

2. **券名称**：展示当前订单实际使用的券名称。
    - 使用体验权益下单时展示对应体验券名称。

3. **券类型**：满减券、折扣券在券名称后用括号标识。
    - 体验券不额外拼接内部权益类型名称。

4. **优惠金额**：展示本订单实际记录的优惠金额，单位元，保留两位小数。
    - 不直接使用券模板面额代替订单实际优惠。

5. **已使用券的展示**：按本订单实际使用的券展示优惠信息。
    - **价格券**：「{券名称}（{券类型}），优惠 ¥{优惠金额}」。
    - **体验券**：「{券名称}，优惠 ¥{优惠金额}」。
    - **零优惠**：已用券且实际优惠为 0 时，展示「0.00」。

6. **未使用券**：订单未关联优惠券或体验权益时，优惠信息明确展示「未使用优惠券」。

7. **关联信息缺失**：订单存在用券关联，但券名称暂时不可取得时，展示「优惠券信息暂不可用」，保留订单已有实际优惠金额。
    - 不得误显示「未使用优惠券」。

8. **数据一致性**：展示该订单实际记录的优惠结果。
    - 券后续暂停、结束、改名或用户领取其他券，不得将本订单实际优惠金额替换为新券配置或其他订单金额。

9. **展示边界**：本期不在订单详情增加券码、体验券编号、体验次数、使用状态或发放人。
    - 若需查看用户券当前状态，使用后台「券使用记录」。

## 三、订单详情（优惠券）—查看与刷新说明

1. **打开详情**：按所选订单展示对应优惠信息，切换查看另一订单时更新为该订单内容。

2. **订单变化**：订单支付、取消或退款后的金额与订单详情保持一致。
    - 「优惠金额」描述该订单记录的优惠，不把优惠券是否返还混入名称或另加未确认字段。

3. **只读信息**：「优惠信息」不提供复制链接、重新发券、修改优惠金额或跳转券码操作。
