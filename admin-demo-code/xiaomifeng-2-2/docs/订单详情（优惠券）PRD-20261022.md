# 订单详情（优惠券） PRD

> 版本 v1.0　·　日期 2026-10-27

*需求场景：运营人员查看套餐订单详情时，需要直接确认该订单用了什么券，以及该券为这笔订单优惠了多少金额。*

| --- | --- | --- | --- |

## 一、订单列表—金额字段

1. **应付金额**：展示订单主题配置的当前售价，单位元，保留两位小数。

2. **优惠金额**：订单使用优惠券或体验权益时，展示该订单实际优惠金额；未使用时展示「¥0.00」。

3. **实付金额**：将原「金额」列改名为「实付金额」，展示订单实际支付金额，单位元，保留两位小数。

## 二、订单详情（优惠券）-增加「优惠信息」

1. **优惠信息格式**：
    - **关联优惠券时**：统一展示「{优惠券名称}（{优惠券类型}），优惠 ¥{优惠金额}」。体验券订单追加展示本次使用的{体验券编号}。
    - **未使用券**：展示「未使用优惠券」。

2. **退款与返券**：
    - 体验券全额退款后返还原用户；券仍在有效期内时恢复「待使用」。
    - 价格券（满减、折扣、特价券）退款未返券时保持「已使用」。
