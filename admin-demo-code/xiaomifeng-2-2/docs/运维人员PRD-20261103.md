> 版本 v1.0　·　日期 2026-11-03

## 运维人员列表

1. **入口**：点击值班日历「运维人员」，打开「运维人员管理」。
2. **展示字段**：人员列展示姓名与系统账号；联系电话展示当前人员的脱敏号码，缺失时显示「—」；飞书列展示「已绑定」「未绑定」及已绑定人员姓名；操作列展示绑定或解绑，以及「删除」。
3. **新增入口**：点击「新增运维人员」进入已有系统账号选择与飞书核对流程，成功后刷新人员列表；详见《新增运维人员》。
4. **排班资格**：人员在岗即可被单日新增、批量排班和原位调整选择；是否绑定飞书、是否有联系电话不作为排班资格条件。人员已被移除后不再进入可选列表。

## 绑定与解绑

1. **未绑定人员**：点击「绑定飞书」，带入当前人员及系统账号，不允许在该流程切换成其他系统账号。
2. **手机号一致性**：展示和查找均使用该人员联系电话；不得因另一份账号数据缺项而将有联系电话的人员展示为「未配置」。联系电话缺失时明确提示并阻止按手机号查找。
3. **查找及核对**：管理员主动点击「查找飞书账号」；匹配成功后展示系统账号、手机号、飞书姓名和飞书用户标识，核对后点击「确认绑定」。查无匹配不等于未配置手机号，需分别提示。
4. **重复绑定**：若该飞书身份已绑定其他运维人员，则不得保存；本人的当前身份不视为重复。成功后刷新为「已绑定」，不覆盖该人员的原联系电话。
5. **解除绑定**：已绑定人员点击「解除绑定」后，确认中提示当日及未来排班数量，并说明排班保留；确认后状态改为「未绑定」，取消不改变状态。
6. **解绑影响**：解绑不删除人员、不删除排班，也不取消其排班可选资格；详情应同步显示当前绑定状态。
7. **关闭**：绑定流程未确认时关闭，不写入绑定结果。

## 删除运维人员

1. **删除确认**：点击该行「删除」，确认对象为当前人员，提供「删除」「取消」。
2. **当日及未来排班**：当前原型按排班日期判断，只要存在当天或以后日期的记录，即提示「该人员还有待执行排班，请先调整或删除排班」，确认删除不可用。
3. **允许删除**：若不存在当日及未来排班，则确认后移除该人员并提示「运维人员已删除」。历史排班不删除，日历保留原姓名、班次、时间及范围，并在详情提示「人员已移除」。
4. **取消及刷新**：取消不删除；删除成功后列表、后续排班选项同步更新，重新打开页面不自动恢复已删除人员。
5. **账号边界**：删除操作针对运维人员身份，不等于删除系统用户账号；从已有账号添加人员时，仍须校验是否已经加入运维人员。

## 待确认事项

1. **跨天与已结束班次**：当前按日期阻止删除人员，会同时拦截当天已结束排班，也可能遗漏前一天开始但尚未结束的跨天排班。正式删除限制是否改为按实际结束时间判断，待确认。
2. **联系方式维护入口**：缺失或错误联系电话时由哪个已有账号管理入口补充、修改，当前材料未确定；本页不自行新增手机号编辑规则。
3. **真实飞书接入异常**：当前原型仅演示匹配、查无结果和重复绑定；请求失败、权限不足、账号失效的提示及重试规则，待真实接入范围确认。
