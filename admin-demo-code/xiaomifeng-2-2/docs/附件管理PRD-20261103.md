# 附件管理 PRD

> 版本 v1.0　·　日期 2026-11-03

*需求场景：使用方集中维护可复用的处置方案附件，查看被哪些方案引用，并完成上传、预览、下载及删除。*

## 附件列表

1. **入口**：从方案库「附件管理（{数量}）」打开附件管理抽屉，显示附件名称、关联处置方案及操作；默认每页10条。
2. **文件范围**：展示已上传文件及方案已引用的文件名称，同名记录在当前原型中只显示一条；包含已关联、未关联及仅保留文件名但无内容的历史记录。
3. **关联处置方案**：根据当前已保存方案逐个列出引用此文件的方案名称；同一文件可关联多个方案，若没有引用则显示「未关联」。
4. **空列表**：没有附件记录时展示空列表，保留上传入口。新上传未关联文件也应计入附件总数。

## 上传附件

1. **操作**：点击「上传附件」选择文件；支持JPG、JPEG、PNG、DOC、DOCX和PDF，不区分扩展名大小写。不符合时提示「请选择 JPG、PNG、DOCX、DOC 或 PDF 文件」，不加入列表。
2. **成功结果**：文件上传成功即加入附件管理，提示「附件已上传」；从本入口上传不自动新增方案关联，可后续在新建编辑方案中选择。
3. **失败结果**：文件未成功保存时提示失败，列表不增加该文件，保留其他已有文件，允许重试。取消文件选择不改变附件。
4. **持久展示**：已上传文件在再次打开附件管理时仍可查看；删除后的文件不因刷新恢复为演示样例。

## 预览与下载

1. **管理入口**：每行提供「预览」「下载」，操作对象为该文件；方案列表、详情及表单通过同一文件名称获取对应内容。
2. **图片**：JPG、JPEG、PNG在预览窗口中展示图片，长宽适配窗口；预览中提供下载入口。
3. **PDF**：使用文档预览区域查看，并提供下载入口；预览渲染能力依赖浏览器。
4. **Word**：DOC、DOCX提示「当前浏览器不支持直接预览 Word 文件，请下载后查看。」，提供下载，不显示空白预览区冒充成功。
5. **内容缺失**：仅有名称而没有文件内容时不能下载，预览说明内容不可用及可上传同名文件补齐；不删除原关联名称。
6. **关闭预览**：返回附件管理或原查看入口，不改变文件及关联；下载不等于移除文件或改变引用状态。

## 删除附件

1. **二次确认**：点击「删除」后提示「确认删除该附件？」并提供「删除」「取消」。
    - 有方案引用时说明「删除后将同时移除该附件与处置方案的关联。」
    - 未关联时说明「删除后无法恢复。」
2. **确认结果**：删除文件并解除所有已保存方案对该文件的关联，更新附件数量、方案列表附件数量及方案详情；提示「附件已删除」。方案本身保留。
3. **取消与失败**：取消不改变文件和引用；删除失败提示「删除失败，请重试」。
4. **与删除方案的区别**：删除处置方案仅移除其引用关系，附件文件继续保留；删除附件会同时解除全部方案引用。

## 待确认事项

1. **同名文件**：当前原型同名上传替换原文件，可能改变多个关联方案所见内容，正式替换确认或重命名规则待确认。
2. **上传限制及权限**：文件大小、数量、存储容量和上传下载删除权限尚未定义，不能把演示环境限制作为正式标准。
3. **未保存表单联动**：某附件在编辑表单打开期间被删除后，未保存的附件选择如何清理、提交前如何校验，当前未形成完整规则，待确认。
4. **读取及预览异常**：文件读取失败、文件损坏、PDF无法渲染时的统一反馈和重试规则尚需确认；不能把存在文件名称视为文件可用。
