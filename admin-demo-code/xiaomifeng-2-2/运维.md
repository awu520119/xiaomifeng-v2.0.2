# 无人机运维管理系统｜MVP 页面信息架构 V1.0

## 一、整体导航与页面结构

### 1.1 左侧主导航

```text
运维管理
├── 运维工作台
├── 处置管理
│   ├── 告警中心
│   └── 值班排班
├── 运维工单
└── 处置方案库
```

## 二、页面 01｜运维工作台

### 2.1 页面目标

快速了解全部景区设备运行情况、定位异常设备、查看天气风险，并进入告警处置。

### 2.2 页面布局

```text
页面标题：运维工作台
筛选：拍摄点选择 | 设备状态 | 重置

┌────────────────────────────────────────┐
│ 机场总数 │ 无人机总数 │ 异常设备 │ 待处理告警 │
├────────────────────────┬───────────────┤
│                        │               │
│                        │ 实时告警      │
│                        │               │
│       设备地图         ├───────────────┤
│                        │               │
│                        │ 机场信息      │
│                        │ 设备及天气    │
│                        │               │
└────────────────────────┴───────────────┘
```

### 2.3 顶部指标

| 指标 | 展示内容 | 交互 |
|---|---|---|
| 机场总数 | 总数、在线数、离线数 | 点击筛选地图机场 |
| 无人机总数 | 总数、在线数、离线数 | 点击查看设备范围 |
| 异常设备 | 当前存在故障的设备数量 | 点击定位异常设备 |
| 待处理告警 | 当前尚未被确认的告警数 | 点击进入告警中心 |


### 2.4 设备地图

**展示内容**
- 拍摄点及机场地理位置。
- 机场点位名称、当前连接状态、异常提示。
- 点位聚合展示，地图缩放后展开具体机场。
- 使用图标与文字区分正常、异常、离线状态。

**交互规则**
1. 默认展示所有已接入景区及机场。
2. 选择拍摄点后，地图聚焦对应区域。
3. 点击机场点位，右侧展示该机场的设备及天气信息。
4. 点击异常设备，打开设备详情抽屉。
5. 地图优先展示机场，无人机作为机场下属设备查看，避免点位密集。

### 2.5 右侧实时告警

**展示字段**
- 告警等级
- 告警名称
- 所属机场/无人机
- 发生时间
- 处理状态

默认展示最近20条未关闭告警。

**操作**
- 点击告警：打开告警详情抽屉。
- 点击「全部告警」：进入告警中心。
- 严重告警优先展示，同等级按最新发生时间排序。

### 2.6 机场信息及天气

选中机场后展示：

**机场信息**
- 机场名称、所属景区
- 机场连接状态、健康状态
- 关联无人机及其状态
- 最近数据上报时间
- 天气状况、温度
- 风速、降水情况
- 数据更新时间

### 2.7 设备详情抽屉（通用）

**基础信息**
- 设备名称、设备编号
- 设备类型、所属景区及机场
- 连接状态、健康状态
- 最近上报时间

**关联信息**
- 当前未关闭告警
- 最近历史告警
- 关联运维工单

**操作**
- 查看关联告警
- 查看关联工单

## 三、页面 02｜告警中心

### 3.1 页面目标

集中查看异常、确认责任人、执行处置及转换工单。

### 3.2 页面结构

```text
告警中心                         [刷新]

搜索告警 / 设备
[处理状态] [告警等级] [拍摄点] [时间范围]

状态快捷筛选：
全部 | 待处理 | 处理中 | 已关闭

告警列表
────────────────────────────────
列表内容
────────────────────────────────
分页
```

### 3.3 筛选项

| 筛选项 | 类型 | 默认 |
|---|---|---|
| 关键词 | 搜索框，支持告警编号、名称、设备名称 | 空 |
| 处理状态 | 单选 | 未关闭 |
| 告警等级 | 下拉单选 | 全部 |
| 景区 | 下拉单选 | 全部 |
| 时间范围 | 日期范围选择 | 近 7 天 |


### 3.4 列表字段

| 字段 | 展示内容 |
|---|---|
| 告警信息 | 告警名称、告警编号 |
| 告警等级 | 严重 / 一般 / 提示 |
| 所属设备 | 设备名称、机场 |
| 发生时间 | 最新发生时间 |
| 责任人 | 当前负责人员 |
| 处理状态 | 待处理 / 处理中 / 已关闭 |
| 关联工单 | 工单编号，无则显示「—」 |
| 操作 | 查看详情 |

默认按最新发生时间排序。

### 3.5 告警详情抽屉

**顶部**
- 告警名称
- 告警等级、当前处理状态
- 告警编号

**异常信息**
- 所属景区 / 机场 / 设备
- 故障类型、错误码（如有）
- 首次发生时间、最近发生时间
- 告警描述
- 当前设备运行状态

**处置信息**
- 当前责任人
- 响应时间
- 关联工单
- 飞书通知对象及发送结果

**辅助信息**
- 推荐处置方案，最多展示 3 条
- 处置时间线，记录通知、认领、转派、处理及关闭动作

**底部操作**

根据状态展示不同操作：

| 状态 | 主操作 | 次操作 |
|---|---|---|
| 待处理 | 处置 | 转派 |
| 处理中、无工单 | 关闭告警 | 创建工单、转派 |
| 处理中、有工单 | 查看工单 | 关闭告警、转派 |
| 已关闭 | 无 | 查看记录 |

### 3.6 核心交互规则

**确认响应**
- 点击后状态由「待处理」变为「处理中」。
- 自动记录响应人员及响应时间。
- 默认责任人为值班人员，其他有权限的运维人员可以认领或转派。

**直接关闭**
- 弹出确认窗口。
- 必填处置结果。
- 记录操作人及时间。
- 关闭告警不直接修改设备实际运行状态。

**创建工单**
- 打开新建工单抽屉。
- 自动填入告警名称、设备、景区、故障描述及来源告警。
- 创建后告警关联工单编号。
- 同一告警已有未完成工单时，优先引导查看原工单，避免重复创建。

**转派**
- 选择新责任人并确认。
- 更新当前责任人，记录转派操作。
- 触发新责任人的通知。

## 四、页面 03｜值班排班

### 4.1 页面目标

维护运维人员班次，支持快速调整，确保设备故障能够准确匹配并通知当班人员。

### 4.2 页面布局

```text
值班排班

[上一月]  2026年10月  [下一月]
[值班范围] [今天]          [班次设置] [新增排班]

┌──────────────────────────┬───────────────┐
│                          │               │
│                          │ 选中日期      │
│        月历视图          │               │
│                          │ 当日班次      │
│     日期 / 班次 / 人员    │ 值班人员      │
│                          │ 联系方式      │
│                          │               │
└──────────────────────────┴───────────────┘
```

### 4.3 月历视图

每日单元格展示：
- 日期
- 班次名称
- 主值班人员
- 未排班提示

一个日期可以展示多个班次。

排班较多时仅显示前两项，其余通过「+N」展开，不撑高整个日历。

### 4.4 日期详情面板

点击日期后展示当天全部班次：

| 字段 | 内容 |
|---|---|
| 日期 | 当前选中日期 |
| 班次 | 早班 / 晚班或自定义名称 |
| 工作时段 | 开始、结束时间 |
| 主值班人员 | 姓名 |
| 飞书账号 | 绑定账号 |
| 联系电话 | 手机号 |
| 责任范围 | 全局或指定景区 |
| 操作 | 编辑 / 删除 |

### 4.5 新增 / 编辑排班

采用弹窗或右侧编辑面板。

**表单字段**
- 值班日期（必填）
- 班次（必填）
- 值班范围（必填，默认全局）
- 主值班人员（必填）

选择人员后，自动关联其飞书账号及联系电话，无需每次重复填写。

**交互规则**
1. 点击日期可快速新增该日排班。
2. 点击已有班次进入编辑。
3. 支持调整日期、班次和责任人。
4. 排班保存后立即更新日历。
5. 同一范围存在冲突排班时提示，避免自动通知匹配不明确。
6. 无排班时突出提示，并使用预设的默认运维负责人兜底。

班次跨越午夜时，根据班次实际起止时间匹配人员，而非仅匹配日期。

### 4.6 班次设置

在当前页面通过轻量弹窗完成，不独立增加页面。

**字段**
- 班次名称
- 开始时间
- 结束时间

支持添加、编辑、停用班次。

不在首版提供复杂轮班规则或自动排班算法。

## 五、页面 04｜运维工单

### 5.1 页面目标

提供设备故障上报、任务分配、处置跟踪和结果归档。

### 5.2 工单列表

**页面结构**

```text
运维工单                       [+ 新建工单]

[全部] [待接单] [处理中] [已完成]

[搜索工单] [景区] [责任人] [来源] [时间]

工单列表
───────────────────────────────
列表内容
───────────────────────────────
分页
```

**列表字段**

| 字段 | 内容 |
|---|---|
| 工单信息 | 工单标题、编号 |
| 来源 | 告警转入 / 人工上报 |
| 所属设备 | 景区、机场、设备名称 |
| 优先级 | 高 / 中 / 低 |
| 负责人 | 当前处理人员 |
| 状态 | 待接单 / 处理中 / 已完成 |
| 更新时间 | 最近操作时间 |
| 操作 | 查看详情 |

默认展示未完成工单。支持搜索工单标题或编号。

### 5.3 新建工单抽屉

**表单字段**

| 字段 | 要求 |
|---|---|
| 工单标题 | 必填 |
| 工单来源 | 自动记录，告警转入或人工上报 |
| 所属景区 | 必填 |
| 关联设备 | 必填，按景区筛选可选设备 |
| 故障描述 | 必填 |
| 优先级 | 必填，默认中 |
| 负责人 | 必填 |
| 附件 | 可选，支持图片和文件 |
| 来源告警 | 告警转工单时自动关联 |

**操作**
- 取消
- 创建工单

告警转入时预填相关内容，允许补充或修改描述。创建成功后跳转新工单详情。

### 5.4 工单详情页

工单处理具有连续性和较多记录，建议采用独立页面。

**页面布局**

```text
返回工单列表

工单标题           [状态] [转派] [处理操作]

┌──────────────────────┬────────────────────┐
│                      │                    │
│ 故障信息             │ 工单基本信息       │
│                      │                    │
│ 故障描述、图片       │ 负责人、优先级     │
│ 关联设备、告警       │ 来源、创建时间     │
│                      │                    │
├──────────────────────┴────────────────────┤
│                                           │
│ 处理记录 / 操作时间线                     │
│                                           │
│ 处理人、操作时间、描述、附件              │
│                                           │
└───────────────────────────────────────────┘
```

**信息内容**

- 基础信息：工单编号、来源、状态、优先级、负责人、创建时间。
- 故障信息：景区、机场、设备、故障描述、附件。
- 关联信息：来源告警、当前设备状态、推荐方案。
- 处理记录：操作类型、人员、时间、处置内容、附件。

### 5.5 工单状态与操作

| 状态 | 主操作 | 次操作 |
|---|---|---|
| 待接单 | 接单 | 转派、取消 |
| 处理中 | 完成工单 | 添加处理记录、转派 |
| 已完成 | 无 | 查看记录 |
| 已取消 | 无 | 查看取消原因 |

**接单**
- 状态变更为「处理中」。
- 记录接单人员与时间。

**添加处理记录**
- 填写处理说明，可上传图片。
- 保持当前工单状态不变。

**转派**
- 更换负责人。
- 保存历史负责人及操作时间。
- 通知新负责人。

**完成工单**
- 必填故障原因及处理结果。
- 保存完成时间及操作人。
- 如果关联的告警尚未关闭，提示确认该告警是否已经解决。
- 不因工单完成自动假定设备恢复正常。

**取消工单**
- 必填取消原因。
- 保留取消前的所有处置记录。

## 六、页面 05｜处置方案库

### 6.1 页面目标

通过快速检索和结构化方案内容，帮助运维人员解决常见设备故障。

### 6.2 页面结构

```text
处置方案库                     [+ 新建方案]

[搜索方案名称 / 故障码]
[设备类型] [故障类型] [状态]

方案列表
────────────────────────────────
列表内容
────────────────────────────────
分页
```

### 6.3 列表字段

| 字段 | 内容 |
|---|---|
| 方案名称 | 标题 |
| 故障类型 | 网络异常、硬件异常等 |
| 适用设备 | 设备类型 / 型号 |
| 更新时间 | 最近更新日期 |
| 状态 | 已启用 / 已停用 |
| 操作 | 查看 / 编辑 |

点击方案标题打开详情抽屉。

### 6.4 方案详情抽屉

**展示内容**
- 方案名称
- 适用设备类型及型号
- 适用故障类型 / 错误码
- 故障现象
- 可能原因
- 处置步骤
- 注意事项
- 相关附件
- 最近更新时间

处置步骤应按顺序展示，便于运维人员逐项查看。

**操作**
- 编辑方案
- 启用 / 停用

### 6.5 新建 / 编辑方案

**表单字段**
- 方案名称（必填）
- 适用设备类型（必填）
- 故障类型（必填）
- 设备型号（可选）
- 关联错误码（可选）
- 故障现象
- 可能原因
- 处置步骤（必填）
- 注意事项
- 附件上传

支持添加多个步骤，并调整顺序。

**交互规则**
1. 输入关键词实时搜索或提交检索。
2. 方案标题点击后查看详情。
3. 在告警、工单中根据错误码优先匹配方案，其次匹配设备类型及故障关键词。
4. 无匹配方案时显示「暂无匹配方案」，提供前往方案库检索的入口。
5. 停用方案不再参与推荐，但历史引用仍可查看。

首版不增加复杂的知识分类树、内容审批流及 AI 对话入口。

## 七、全局交互与状态规则

### 7.1 跨模块关联

- 工作台点击告警 → 告警详情抽屉。
- 告警详情点击创建工单 → 预填工单创建抽屉。
- 创建工单成功 → 工单详情页。
- 工单详情点击来源告警 → 查看对应告警详情。
- 告警或工单点击推荐方案 → 方案详情抽屉。
- 工作台点击设备 → 设备详情抽屉。
- 飞书通知中的处理链接 → 对应告警或工单详情。

### 7.2 操作反馈

- 创建、保存、转派、认领成功时给予简短提示。
- 关闭告警、完成工单、删除排班等重要操作使用确认交互。
- 表单校验优先在字段旁明确说明问题。
- 操作完成后更新当前状态、时间和操作记录，无需用户手动刷新。
- 抽屉中未保存的表单内容，关闭前给予放弃修改提示。

### 7.3 空状态与异常状态

必须覆盖以下场景：

- 无告警：显示暂无待处理告警。
- 无工单：显示暂无相关工单，并提供新建入口。
- 无排班：提示当前时段无人值班及兜底责任人。
- 天气获取失败：显示数据不可用及更新时间。
- 无匹配方案：保留手动检索入口。
- 飞书通知失败：展示发送失败，并允许重试。
