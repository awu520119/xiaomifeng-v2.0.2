## 一、优惠券列表—权限说明

1. **页面和功能权限**：
    - **统一条件**：勾选【营销管理】-【优惠券管理】下的权限
2. **数据权限**：
    - **平台和租户管理员**：默认有全部券的发放权限；
    - 其他账号能看到的券列表，由单券的「发券权限」控制。
 

## 二、优惠券列表—筛选项说明
1. .**券名称**：关键词输入。按券名称包含关键词匹配，支持清空。

2. **券类型**：单选。「满减券」「折扣券」「体验券」，支持清空。

3. **状态**：单选。「发放中」「已暂停」「已结束」。

4. **拍摄点**：单选。展示拍摄点选项。
    - 选择后匹配适用于该点的券。


## 三、优惠券列表—列表说明
1. **券名称**：展示优惠券名称，支持点击打开「优惠券详情」。

2. **适用范围**：
    - 价格券展示适用拍摄点与主题。
    - 体验券展示配置的可兑换体验主题。
    - 长内容支持查看全文。

3. **状态**：展示券模板的发放状态，包括已结束、已暂停、发放中。
    | 判定条件 | 状态 | 展示颜色 |
    | --- | --- | --- |
    | 剩余发放量为 0 | 「已结束」 | 灰色 |
    | 剩余量大于 0，且已人工暂停 | 「已暂停」 | 橙色 |
    | 剩余量大于 0，且未暂停 | 「发放中」 | 绿色 |

4. **已领取/总量**：展示已被用户领取的券数量与配置总量。


## 四、优惠券列表—操作说明

1. **发放**：对应「满减券」和「折扣券」，下拉可选择「定向发放」「公开发放」。
    - 无权限时禁用。
    - 定向发放同原逻辑；公开发放回显领取二维码和链接。详见《》

2. **查看券码**：对应「体验券」类型。
    - 指定体验券码的定向发放在「券码详情」完成。详见[《发券 PRD》](发券PRD-20261022.md)。

3. **发券权限**：实际发放须同时满足「具有发券功能权限」和「已获得目标券发放授权」。
    - 平台管理员和超级管理员默认拥有该权限
    - 支持添加其他账号发起该券的权限。

4. **暂停发放**：点击后展示确认「暂停发放这张优惠券？」及说明「暂停后不能继续发放或领取，已领取的券仍按原规则使用。」。
    - 确认后停止新增发放和领取，保留已领取券。

5. **恢复发放**：已暂停且仍有剩余额度时允许恢复。
    - 剩余量为 0 时不允许恢复，提示「优惠券剩余量为 0，不能恢复发放」。
    - 恢复后券模板展示「发放中」，因模板暂停而停止领取的公开入口同步恢复，领取时仍校验共用剩余量。

6.  **编辑**：仅支持编辑「优惠券名称」和「使用规则」
