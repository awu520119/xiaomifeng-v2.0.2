# 优惠券列表 PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：运营人员查询优惠券类型、适用范围和发放状态，并进入创建、详情、发放及券码管理。*

## 一、优惠券列表—权限说明

1. **页面入口**：在「营销管理」下进入「优惠券管理」，默认展示优惠券列表。

2. **功能权限**：页面访问、创建、编辑、发券、发券权限配置及暂停或恢复发放分别受对应功能权限控制。
    - 未取得操作权限时，不允许执行对应动作。

3. **单券授权**：实际发放须同时满足「具有发券功能权限」和「已获得目标券发放授权」。此授权不用于隐藏管理列表或只读详情。
    - 系统管理员发券时同样受单券授权约束。

4. **权限配置**：配置单券发券账号须具有发券权限配置功能权限，配置人不必在目标券的发放授权名单内。
    - 字段及保存结果见[《优惠券详情 PRD》](优惠券详情PRD-20261022.md)。

## 二、优惠券列表—筛选项说明

1. **筛选规则**：条件共同生效，未选择条件时不限制该项。
    - 本页不提供日期范围筛选。

2. **券名称**：关键词输入。按券名称包含关键词匹配，支持清空。

3. **券类型**：单选。「满减券」「折扣券」「体验券」，支持清空。

4. **状态**：单选。「发放中」「已暂停」「已结束」，含义见「状态与计算口径」。

5. **拍摄点**：单选。展示拍摄点选项。
    - 选择后匹配适用于该点的券，包含「全部拍摄点」适用券。

6. **查询与重置**：修改或清空条件后回到第 1 页。
    - 点击搜索按钮或回车回到第 1 页。
    - 点击「重置」清空全部条件并回到第 1 页。

## 三、优惠券列表—列表说明

1. **字段顺序**：按下列字段顺序展示，创建时间位于操作项之前。

2. **序号**：根据当前页和每页条数连续编号，跨页不重新从 1 开始。

3. **券名称**：展示优惠券名称，点击打开「优惠券详情」。

4. **券类型**：展示三类券标签。
    - 满减券为暖橙色，折扣券为紫色，体验券为青绿色。

5. **适用范围**：价格券展示适用拍摄点与主题。
    - 体验券展示配置的体验拍摄点与主题。
    - 长内容支持查看全文。

6. **有效期**：展示「领取后 {有效天数} 天可用」，不展示固定起止区间。

7. **状态**：展示券模板的发放状态，见「状态与计算口径」。

8. **已领取/总量**：展示已成功绑定用户的券数量与配置总量。
    - 同一用户多张券分别计数。

9. **创建时间**：展示创建时间，精确到分钟。
    - 历史记录缺失时展示「—」。

10. **操作**：展示「详情」及对应发放入口，其他操作收进更多菜单。

11. **分页**：展示总条数，允许切换页码和每页条数。
    - 每页条数变化后使用新条数展示并保留筛选条件。列表内容独立滚动，分页保持在列表卡底部。

## 四、优惠券列表—操作说明

1. **价格券发放**：满减券和折扣券提供「发放」，其下可选「定向发放」「公开发放」。
    - 不满足「权限说明」中的发放条件或券不可发放时禁用。

2. **体验券操作**：体验券在本列表提供「查看券码」。
    - 指定体验券码的定向发放在「券码详情」完成。移动端三类券的发放见[《发券 PRD》](发券PRD-20261022.md)。

3. **更多操作**：提供「编辑」「发券权限」及「暂停发放」或「恢复发放」。编辑字段见[《创建优惠券 PRD》](创建优惠券PRD-20261022.md)。
    - 授权配置见[《优惠券详情 PRD》](优惠券详情PRD-20261022.md)。

4. **暂停发放**：点击后展示确认「暂停发放这张优惠券？」及说明「暂停后不能继续发放或领取，已领取的券仍按原规则使用。」。
    - 确认后停止新增发放和领取，保留已领取券。

5. **恢复发放**：已暂停且仍有剩余额度时允许恢复。
    - 剩余量为 0 时不允许恢复，提示「优惠券剩余量为 0，不能恢复发放」。

## 五、优惠券列表—状态与计算口径

1. **券类型**：本期仅提供「满减券」「折扣券」「体验券」。
    - 三类券在各页面使用相同名称及颜色。

2. **券模板状态**：管理列表、优惠券详情和发券中心共用下表。
    - 按表中顺序判定，不与用户券使用状态混用。

    | 判定条件 | 状态 | 展示颜色 |
    | --- | --- | --- |
    | 剩余发放量为 0 | 「已结束」 | 灰色 |
    | 剩余量大于 0，且已人工暂停 | 「已暂停」 | 橙色 |
    | 剩余量大于 0，且未暂停 | 「发放中」 | 绿色 |

3. **额度**：定向发放、公开领取及体验券码领取共用券总量。
    - **占用时机**：实际绑定用户后计入已领取和额度占用；未领取券码的自动备码不占用额度。
    - **作废处理**：券作废后不返还额度；未领取券码作废同样占用额度。
    - **剩余数量**：剩余量 = 总量 − 占用数量，最低为 0。

4. **用户券状态**：已领取券的「待使用、使用中、已使用、已使用（退款）、已过期、已作废」含义统一引用[《券使用记录 PRD》](券使用记录PRD-20261022.md)「使用状态说明」。
    - 未绑定券码另展示「未领取」。

5. **有效期**：模板仅配置领取后有效天数。
    - **起算时机**：领取成功或定向发放到账时，记录领取时间。
    - **截止计算**：截止时间 = 领取时间 + 有效天数，时分秒与领取时刻相同。
    - **时间举例**：2026-10-22 14:30:00 领取、有效 7 天，截止为 2026-10-29 14:30:00。
    - **失效判定**：超过截止时刻失效，不延长到当天 23:59:59。

6. **时间起算与保留**：未领取券码不启动计时。
    - 二维码下载、打开或重复查看不重新起算。已领取券保留领取时确定的截止时间。
    - 本期不配置固定有效期区间或单独的领取截止时间。

7. **信息刷新**：打开页面、返回列表或完成创建、编辑、授权、发放、暂停及恢复操作后，展示最新已保存信息。
    - 各处已领取数、剩余量及状态基于同一张券的实际领取结果计算。
