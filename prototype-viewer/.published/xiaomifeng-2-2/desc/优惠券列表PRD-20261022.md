## 一、优惠券列表—权限说明

1. **权限说明**：
    - **权限控制**：由【优惠券管理】-【优惠券列表】中的权限控制，包括查看、编辑、发放（原定向发放）、配置发券权限
    - **数据权限**：
        - **内置角色**：平台、租户管理员、平台运营员默认能看全部的优惠券列表；默认有优惠券列表的全部权限
        - **其他角色**：其他角色账号只能看到被授权的优惠券的列表。

## 二、优惠券列表—筛选项说明

1. **券名称**：关键词输入。按券名称包含关键词匹配，支持清空。

2. **券类型**：单选。「满减券」「折扣券」「特价券」「体验券」，支持清空。

3. **状态**：单选。「发放中」「已暂停」「已结束」。

4. **拍摄点**：单选。展示拍摄点选项。
    - 选择后匹配适用于该点的券。

## 三、优惠券列表—列表说明
1. **券名称**：展示优惠券名称，支持点击打开「优惠券详情」。

2. **适用范围**：
    - 价格券（满减、折扣、特价）：展示适用拍摄点与主题。
    - 体验券：展示配置的可兑换体验主题。
    - 长内容支持查看全文。

3. **状态**：展示券模板的发放状态，包括已结束、已暂停、发放中。
| 判定条件 | 展示状态 |
| :--- | :---: |
| 剩余发放量 = 0 | 已结束 |
| 剩余发放量 > 0，且已人工暂停 | 已暂停 |
| 剩余发放量 > 0，且未暂停 | 发放中 |

4. **已领取/总量**：展示已被用户领取的券数量与配置总量。

## 四、优惠券列表—操作说明

1. **发放**：对应「满减券」「折扣券」和「特价券」，下拉可选择「定向发放」「公开发放」。
    - **无权限，或券状态为「已暂停」「已结束」**：「发放」按钮禁用。
    - 定向发放规则见<a href="../index.html?node=xiaomifeng-2-2--coupon-directed" target="_top" onclick="if(window.parent!==window){window.parent.postMessage({type:'gotoNode',id:'xiaomifeng-2-2--coupon-directed'},'*');return false;}">《定向发放 PRD》</a>；公开发放规则见<a href="../index.html?node=xiaomifeng-2-2--coupon-public" target="_top" onclick="if(window.parent!==window){window.parent.postMessage({type:'gotoNode',id:'xiaomifeng-2-2--coupon-public'},'*');return false;}">《公开发放 PRD》</a>。

2. **查看券码**：对应「体验券」类型。
    - 券码列表规则见<a href="../index.html?node=xiaomifeng-2-2--coupon-codes" target="_top" onclick="if(window.parent!==window){window.parent.postMessage({type:'gotoNode',id:'xiaomifeng-2-2--coupon-codes'},'*');return false;}">《查看券码 PRD》</a>。

3. **发券权限**：
    - 配置规则见<a href="../index.html?node=xiaomifeng-2-2--coupon-authorization" target="_top" onclick="if(window.parent!==window){window.parent.postMessage({type:'gotoNode',id:'xiaomifeng-2-2--coupon-authorization'},'*');return false;}">《发券权限 PRD》</a>。

4. **暂停发放**：
    - 点击后展示确认「暂停发放这张优惠券？」及说明「暂停后不能继续发放或领取，已领取的券仍按原规则使用。」。
    - 确认后停止新增发放和领取，保留已领取券。

5. **恢复发放**：已暂停且仍有剩余额度时允许恢复。
    - 剩余量为 0 时不允许恢复，提示「优惠券剩余量为 0，不能恢复发放」。
    - 恢复后券模板展示「发放中」，因模板暂停而停止领取的公开入口同步恢复，领取时仍校验共用剩余量。

6. **编辑**：仅支持编辑「优惠券名称」和「使用规则」。
