## 一、券使用记录—权限说明

1.  **权限控制**：
    - 须具有「营销管理」下「优惠券管理」的「查询」/「编辑」功能权限。
    - **作废**：须具有「营销管理」下「优惠券管理」的「作废」权限。
    - **数据权限**：被授权发券用户只能看被授权的券使用记录。平台管理员和租户管理员可看全部


## 二、券使用记录—筛选项说明

1. **筛选规则**：各项共同生效，未填写条件不限制对应项。

2. **券名称、券码、手机号**：关键词输入。按任一对应字段包含关键词匹配。
    - 手机号支持完整号码查询，页面按脱敏结果展示。

3. **获取时间**：日期范围。以用户券实际绑定时间查询，包含所选开始日和结束日全天。
    - 支持清空。

4. **获取方式**：单选。「定向发放」「公开领取」「券码领取」，支持清空。

5. **使用状态**：单选。包括待使用、使用中、已使用、已使用（退款）、已过期、已作废，支持清空。

## 三、券使用记录—列表说明

1. **使用状态**：
    | 状态 | 业务含义与触发条件 |
    | --- | --- | --- |
    | 「待使用」 | 已领取，仍有效，未被订单占用且尚未完成该券对应使用；体验权益到账本身不表示已完成服务 |
    | 「使用中」 | 价格券被待支付订单占用；或体验券已创建体验订单但尚未完成服务 |
    | 「已使用」 | 价格券已经用于成功支付；或体验券已完成对应体验服务 | 
    | 「已使用（退款）」 | 已使用的价格券发生退款且不满足返还条件，券保持使用终态 |
    | 「已过期」 | 未作废、未完成使用且未被订单占用，并已超过单券截止时间，不可继续使用 | 
    | 「已作废」 | 人工执行作废成功，不可继续使用 |

2. **关联订单号**：展示当前占用订单或已关联订单。
    - 有订单时支持复制及查看完整号码，无订单展示「—」。
    - 有多个订单时显示多个订单号，用“，“隔开。

3. **获取方式**：展示「定向发放」「公开领取」「券码领取」。

4. **有效期**：第一行展示领取后有效天数，第二行展示已固化的具体截止时间。

5. **排序**：按获取时间倒序。
