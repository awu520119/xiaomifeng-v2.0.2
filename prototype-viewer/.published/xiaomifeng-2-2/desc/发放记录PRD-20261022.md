# 发放记录 PRD

> 版本 v1.0　·　日期 2026-10-22

*需求场景：工作人员在手机上查看本人发出的券及公开入口领取情况，核对接收用户、领取时间、券状态和有效截止时间。*

## 一、发放记录—权限说明

1. **页面入口**：在「营销管理」的「发券中心」切换至「发放记录」，直接使用当前登录账号。

2. **访问权限**：须具有发券中心访问权限；账号与页面访问规则引用[《发券 PRD》](发券PRD-20261022.md)「权限说明」。

3. **数据范围**：仅展示本人定向发放、本人创建的公开领取入口及通过这些入口领取的券，不展示其他发放人员的个人记录。

4. **授权变化**：目标券发放授权被撤销后，既有本人发放记录保留；券被使用、退款、过期或作废后仍可追溯原记录。

5. **状态口径**：券类型及模板发放状态引用[《优惠券列表 PRD》](优惠券列表PRD-20261022.md)「状态与计算口径」；单张用户券使用状态引用[《券使用记录 PRD》](券使用记录PRD-20261022.md)「使用状态说明」。

## 二、发放记录—筛选与记录范围

1. **记录筛选**：在「发放记录」提供「全部」「定向发放」「公开领取」单选筛选，默认「全部」。
    - 各组按对应发放时间或入口创建时间倒序。无记录时展示「暂无发放记录」。

2. **记录层级**：定向发放按单张用户券展示。
    - 公开领取按入口展示，将领取用户明细折叠在对应入口卡内，不另拆为平行的领取结果分组。

## 三、发放记录—定向发放列表说明

1. **券名称、券类型**：说明本人发出的具体券及类型。

2. **使用状态**：展示该张用户券当前使用状态，与后台券使用记录一致。

3. **发给**：接收用户脱敏手机号，作为重点信息。

4. **发放时间**：实际发放到账时间，精确到分钟。

5. **有效截止**：已确定的单券截止时间。

6. **券码/体验券编号**：价格券展示券码，体验券展示独立体验券编号。
    - 支持复制。

## 四、发放记录—公开领取入口说明

1. **券名称、券类型**：说明该入口可领取的具体券及类型。

2. **发放状态**：展示对应券模板的当前状态，不作为单张用户券的使用状态。

3. **已领取**：仅统计通过当前入口成功绑定用户的券张数，单位张。

4. **创建时间**：当前入口创建时间，精确到分钟。

5. **领取明细**：展示当前入口明细数量，默认收起，点击可展开或收起。

## 五、发放记录—领取明细说明

1. **使用状态**：当前用户券状态，与后台券使用记录使用同一规则及颜色。

2. **领取用户**：领取用户脱敏手机号。

3. **领取时间**：当前券成功绑定该用户的时间，精确到分钟。

4. **有效截止**：该用户券已确定的具体截止时间。

5. **券码/体验券编号**：与定向发放记录使用同一展示方式，支持复制。

6. **无领取明细**：入口尚无成功领取时，展开后展示「暂未有人领取」。
    - 不生成占位用户或计入已领取数。

7. **状态刷新与记录保留**：打开记录页及发放、领取或用户券状态变化后，展示最新数据。券被使用、退款、过期或作废后仍保留原记录。
    - 本人创建入口的管理状态随对应优惠券状态更新。
